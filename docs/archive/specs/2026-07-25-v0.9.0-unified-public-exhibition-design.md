# 0.9.0 統一公開成果展設計

## 1. 目標

把目前分散於空間參照圖集、日照研究與 3D Viewer 的三個 HTML 入口，整合成一個公開展示建築設計成果的單一網站。網站不是編輯器或內部工作台，而是一份可由一般訪客循序理解、也能供專業讀者深入檢視的數位建築展覽。

觀看順序由設計理念建立整體敘事，再進入專業日照研究、完稿平面／剖面圖，最後以 3D 展示與第一人稱實境漫遊形成體驗高潮。

## 2. 已確認範圍

### 2.1 中文主導覽

主導覽固定為：

1. `設計理念`
2. `日照研究`
3. `圖面設計`
4. `3D 展示`

`設計理念`以「向光、向水、向人、向時間」形成精緻的敘事章節；既有公開理念正文、active token、數值與限制不因版面重整而被改寫。`向水`作為公開展示的上位章名，涵蓋既有「向雨而生」、被動雨簾、雨水收集與再利用內容。

### 2.2 單一入口與網址

正式部署只保留一個主要 HTML：

```text
/                                  預設顯示設計理念
/?view=design-concept              設計理念
/?view=solar-study                 日照研究
/?view=drawings                    圖面設計
/?view=3d-viewer                   3D 展示與實境漫遊
```

使用 query route 是為了讓 GitHub Pages 在沒有 SPA rewrite 的情況下仍由同一個 `index.html` 直接載入。缺少或無效的 `view` 值一律回到 `design-concept`，不得產生空白頁。

舊 `/solar-study/` 與 `/3d-viewer/` 入口直接淘汰，不建立轉址 HTML 或相容頁。

### 2.3 內容定位

- `設計理念`：公開成果的序章與策展敘事，優先呈現「為什麼這樣設計」。
- `日照研究`：保留專業性、完整控制與限制說明，並以設計理念引導讀者理解研究目的。
- `圖面設計`：以線上建築圖冊呈現現行完稿平面、剖面及基地資料。
- `3D 展示`：保留構件檢視、場景、圖層、固定視角、WebGL fallback 與第一人稱漫遊，並以沉浸式畫面作為成果展示高潮。

## 3. 不可變更邊界

0.9.0 是展示架構、版面與視覺系統改版，不是建築設計改版。

下列內容不得因本版改動而改變：

- `model/project-model.json` 的設計幾何、尺寸、方向、狀態與專業核准旗標。
- `model/analysis-registry.json` 的 solar input、inputHash 與分析狀態。
- `reference/generated/viewer-model.json` 與 `concept-content.json` 的內容來源及同步契約。
- V067 現行 SVG／PNG 完稿圖的圖形內容、版本、座標、圖框及檔案。
- 日照計算函式、控制範圍、工作角度、能量數值、專業限制與測試基準。
- 3D 場景幾何、材質語意、選取、碰撞、移動、游泳、畫質階級及 fallback 行為。
- 第一人稱漫遊的 safe spawn、area registry、輸入與物理狀態。

允許變更的只有：

- HTML 入口與外層 DOM 結構。
- 共用導覽、路由、載入與 mount／unmount 生命週期。
- 內容呈現順序、資訊顯示層級與展開／收合方式。
- CSS、色彩、字型角色、字級、行距、留白、元件外觀及響應式版面。
- 不改語意的導覽標籤、章節標籤與輔助說明。
- 套件／網站發行 metadata；active geometry 及分析 inputHash 維持不變。

## 4. 資訊架構

### 4.1 共用網站殼層

所有 view 共用：

- 專案名稱與簡潔識別。
- 四項固定中文主導覽。
- 當前章節狀態與可鍵盤辨識的 active 標記。
- 統一的內容寬度、頁面邊界、字型與色彩 token。
- 概念設計／非施工圖聲明。

主導覽不再使用「返回圖集」「開啟 Viewer」等跨頁連結。專案名稱可返回預設 `design-concept`，不另增加第五個「首頁」導覽項目。

### 4.2 View 模組

`index.html` 只保存根容器與必要 metadata；各 view 由 TypeScript 模組掛載：

```text
reference/src/
├─ app/
│  ├─ bootstrap.ts
│  ├─ router.ts
│  ├─ app-shell.ts
│  └─ navigation.ts
├─ views/
│  ├─ design-concept/
│  ├─ solar-study/
│  ├─ drawings/
│  └─ 3d-viewer/
└─ design-system/
   ├─ tokens.css
   ├─ typography.css
   ├─ layout.css
   └─ components.css
```

現有日照、圖面與 3D 邏輯保留在原本模組中，view adapter 只處理掛載、卸載與展示殼層。3D 程式只在 `3d-viewer` 啟用時動態載入；離開後必須釋放事件、animation frame、WebGL 與可釋放資源，不得在其他 view 背景持續執行。

## 5. 視覺方向

整體風格定義為「優雅、舒服、克制的建築刊物與數位展覽」。

- 主色：溫暖圖紙白、炭墨黑、泳池藍綠、混凝土灰。
- 強調色：少量陶土紅或柔和金棕，只用於目前章節及重要研究提示。
- 取消大面積漸層、發光、密集膠囊標籤與每張卡片都有陰影的做法。
- 圓角以 0～6 px 為主；浮動手機工具或必要 overlay 才可適度增加。
- 以細線、留白、比例與排版建立層級，不以裝飾效果堆疊層級。
- 中文為主要閱讀語言，英文只保留技術代號、版本、座標及必要 caption。

### 5.1 字型角色

- 展覽標題：`Noto Serif TC`／`Songti TC`／襯線 fallback。
- 正文與控制：`Noto Sans TC`／`PingFang TC`／`Microsoft JhengHei`／無襯線 fallback。
- 尺寸、座標、版本與模型 hash：`ui-monospace`／等寬 fallback。

正式頁面不得為字型存取外部 runtime origin；若需要一致字型資產，必須採 repository-local、具授權且經效能預算驗證的檔案。

## 6. 各 View 版面

### 6.1 設計理念

- 首屏以專案名稱、核心句與克制的主視覺建立作品氣質。
- 「向光、向水、向人、向時間」採章節式排版，不使用等寬四卡片儀表板。
- 大段敘事控制閱讀寬度與行長，透過圖文節奏、引言、留白及章節編號形成層次。
- 專業數值仍由 active token 帶入，不複製或硬編碼第二份答案。

### 6.2 日照研究

- 保留完整研究摘要、平面／剖面 SVG、控制器、即時讀值、代表時刻、方法與限制。
- 首段先交代「向光」設計理念與研究問題，再進入專業工具。
- 結論、工作值與限制保持高辨識；說明性 metadata 可收進「研究方法與限制」。
- 不得以視覺簡化弱化 23° 外傾、暖季／冷季能量、inputHash 或專業驗證警語。

### 6.3 圖面設計

- 圖面本體獲得最大顯示面積，外圍介面採圖冊式細線與圖紙留白。
- 保留 current sheet tab、SVG 內嵌、圖層控制、縮放與 ID 選取。
- V067 SVG／PNG 不重繪、不後製、不改字與不裁圖框。
- 圖面目錄、操作工具與詳情面板可因螢幕寬度改變位置，但行為不變。

### 6.4 3D 展示

- 模型畫布為主角；場景、圖層、構件資訊與技術狀態採可漸進展開的控制層。
- 第一人稱漫遊保留在同一 view，不建立第五個入口。
- 桌面可保留左右資訊區；手機改為不遮住主要畫面的可收合控制區。
- 3D 深色沉浸背景可以與明亮刊物頁面形成對比，但字型、主導覽、強調色與互動語言必須同屬一套設計系統。

## 7. 手機版原則

最低支援寬度維持 320 px，主要驗收使用 390 × 844，另以 768 px 檢查平板轉折。

- 頁面不得產生整體水平溢出。
- 手機導覽使用兩列式緊湊 header：第一列專案識別，第二列可水平滑動的四項文字導覽；不以漢堡選單隱藏主要章節。
- active 導覽以底線、字重或細色條表達，不使用四個大型膠囊。
- 主要觸控目標至少 44 CSS px，並支援 safe-area inset。
- 設計理念與日照文章改成單欄閱讀，正文行長與段距優先於桌面卡片排列。
- 日照控制器保留既有 sticky 即時預覽，避免滑桿與回饋圖分離。
- 圖面保留完整圖框，透過局部捲動／縮放查看，不以裁切換取滿版。
- 3D 畫布、漫遊雙觸控區、上浮／下潛、返回與退出控制不得被共用導覽遮擋。
- 旋轉、切 view、返回及重載後不得出現重複 listener、殘留 overlay 或失焦控制。

## 8. 成功條件

1. `dist/reference/` 正式部署只含一個主要 `index.html`，不再產生三個公開入口。
2. 四個 view 都能由 query URL 直接載入，無效 route 安全回到設計理念。
3. 原始資料、現行圖面、日照數值、模型幾何與 3D／漫遊行為均無語意差異。
4. 桌面、390 × 844、320 px 與平板寬度皆無整頁水平溢出，導覽與內容閱讀流暢。
5. 視覺上形成同一作品的統一識別，同時保留日照研究的專業密度與 3D 的沉浸感。
6. 鍵盤、觸控、reduced motion、WebGL fallback 及既有自動測試持續通過。

## 9. 非目標

- 不重新設計建築、圖面、模型或日照方案。
- 不重跑日照最佳化。
- 不新增施工、結構、機電、消防或法規結論。
- 不導入 React、Vue 或新的後端。
- 不保留舊網址、轉址頁或多入口建置。
- 不為美化加入與設計無關的生成式背景圖、假照片或虛構成果。
