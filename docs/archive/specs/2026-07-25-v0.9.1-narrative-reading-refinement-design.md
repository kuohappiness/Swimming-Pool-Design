# 0.9.1 敘事與閱讀體驗精修設計

- 日期：2026-07-25
- 類型：design
- 狀態：completed
- 完成日期：2026-07-25
- 任務：TASK-083
- 目標版本：0.9.1

## 1. 目標

在不改動建築設計、日照結果、現行圖面與 3D 行為的前提下，讓公開成果網站形成更清楚的閱讀旅程：

1. 由最初手繪稿交代作品的初心與問題意識。
2. 由四個設計方向說明方案如何發展。
3. 由日照與圖面提供驗證。
4. 由 3D Viewer 完成空間體驗。

整體介面維持優雅、清楚、流暢且專注；以版面比例、留白、細線與文字層級建立品質，不增加輪播、自動播放、視差、裝飾動畫或大量卡片。

## 2. 資訊架構

主導覽仍固定為「設計理念、日照研究、圖面設計、3D 展示」，不新增第五個手稿入口。

### 2.1 設計理念

閱讀順序調整為：

```text
作品首屏
→ 00 / ORIGIN 手稿與設計起點
→ 01–04 向光、向水、向人、向時間
→ FROM LINE TO SPACE 成果收束
→ 日照研究／圖面設計／3D 展示
```

`00 / ORIGIN` 使用非對稱、安靜的手稿圖集。桌面預留一張主稿與兩張推演／細節稿；手機改為自然單欄。未收到真實素材以前只顯示明確的待收錄狀態，不用生成圖或其他示意圖冒充原稿。

### 2.2 3D 展示

3D 頁只回答「這個空間如何被觀看、選取與走入」：

- 模型畫布是主角。
- 保留五個場景、圖層、固定視角、剖視、構件選取、模型狀態與第一人稱漫遊。
- 右側只顯示當前場景的一段短摘要、三個觀看重點及返回完整設計理念的連結。
- 不再把完整公開理念文章注入 3D 頁。
- WebGL fallback 同樣提供五場景的短摘要與圖面連結，不複製完整文章。

3D view 使用真正的 view fragment，由共用 App Shell 擁有文件、導覽與頁面 metadata；不得再匯入一份含 `html`／`body`／script 的舊完整頁面後拆解。

## 3. 文案策略

手稿段落的核心句為：

> 一切，從紙上的第一筆開始。

正文定位不是懷舊裝飾，而是說明手繪如何先提出空間問題，之後才由角度、數值、圖面與模型逐步回答。此文案寫入公開理念 Markdown 正本；頁面只負責把同一內容分成首屏與 ORIGIN 兩個展示區。

收束句為：

> 從紙上的一筆，走到可以被閱讀、驗證，也能親自走入的空間。

## 4. 手稿素材流程

原始照片放入：

```text
source-materials/concepts/hand-sketches/
```

收件後必須：

1. 保留原始位元組，不直接修改來源檔。
2. 檢查 MIME、byte size、像素尺寸、方向與 SHA-256。
3. 依 `SRC-CONCEPT-012` 起的穩定 ID 命名並登錄 `docs/02_SITE_AND_SOURCES.md`。
4. 確認作者、收到日期、公開使用權與圖說。
5. 另產生網站衍生檔；裁切、校正與壓縮不得覆蓋原檔。

實際張數、主次、橫直向裁切與 captions 必須在看過照片後決定，不先假設每張手稿內容或比例。

## 5. 不可變更邊界

0.9.1 本輪不改：

- `model/project-model.json` 的設計幾何、狀態與專業核准旗標。
- active `GEO-0.8.2`。
- solar inputHash、分析結果、控制範圍與專業限制。
- V067 current SVG／PNG 圖面。
- 3D 模型構件、材質語意、場景相機、圖層、選取、碰撞、移動、游泳、safe spawn 與畫質行為。
- 四項主導覽、query route 與單一 HTML 部署架構。

允許變更公開理念文案正本、view fragment、DOM、場景展示摘要、CSS、響應式閱讀順序及必要測試。

## 6. 驗收條件

1. 設計理念在桌機與手機都清楚呈現「首屏 → 手稿起點 → 四個方向 → 驗證／圖面／走入空間」。
2. 手稿尚未到位時不出現假素材；到位後原始檔與 web derivative 可追溯。
3. 3D DOM 不含完整理念文章，也不再載入一份舊完整 HTML 文件。
4. 3D 五場景在 WebGL 與 fallback 都有短摘要、三個觀看重點與完整理念連結。
5. 320、390、768、1280、1440 px 無整頁水平溢出；桌機 Viewer 首個畫面不被過高序言推離主要視野。
6. 完整 tests、typecheck、build、desktop／mobile／fallback E2E 與視覺檢查通過。
7. 0.9.1 最終版本、release、commit 與 push 必須等真實手稿完成收件與使用者另行指示。

## 7. 非目標

- 不新增主導覽。
- 不為手稿建立輪播、燈箱、視差或自動動畫。
- 不生成或尋找替代手稿。
- 不把完整日照研究、圖面說明或理念文章複製到 3D 頁。
- 不在本次架構工作中發布網站。
