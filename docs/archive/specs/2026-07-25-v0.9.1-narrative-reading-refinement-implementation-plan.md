## 4. TASK-084｜手稿起點與故事收束

- 把 ORIGIN 文案寫入公開理念 Markdown 正本。

## 5. TASK-085｜3D Viewer 專注化

- 把舊完整 HTML 改為 view fragment，移除 DOMParser 與完整頁面殼層搬運。
- 以 `scene-manifest.json` 保存每個場景的短摘要、三個觀察點與理念 anchor。
- 3D runtime 仍驗證 `concept-content.json` 的 modelHash／scene ID，但不渲染完整文章。
- WebGL 與 fallback 共用短場景摘要。
- 壓縮 3D intro 高度，讓桌機主要 Viewer 更早進入視野。
- 更新 E2E 與 source contract 測試。

驗證：五場景、圖層、固定視角、選取、剖視、fallback、漫遊與 model/content trust boundary 不退步；3D DOM 不含 `data-concept-content`。

## 6. TASK-086｜真實手稿收件與上稿

- 檢查並登錄原始檔 MIME、bytes、dimensions、SHA-256、作者、日期、用途與權利。
- 依穩定 source ID 整理來源，不修改原始位元組。
- 產生 web derivative，保留自然紙張質感並只做必要的方向校正、縮放與壓縮。
- 依 `DEC-135` 使用場勘 2／5／6 與五張非樓梯手稿，排成現場觀察到方案深化的順序。
- 以使用者明示的選圖限制完成 captions 並替換待收錄狀態。
