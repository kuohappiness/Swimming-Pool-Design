01
向光
向光而轉
讓建築回應季節與太陽。

「方向」既是建築在基地上的朝向，也是泳池走向新階段的設計方向。

設計固定 1F／2F 與原有建築基準，只讓 3F 本體由原軸線順時針水平旋轉 25.5°，並使面向泳池的鏡面牆向池側外傾 23°。

兩個角度各自扮演不同角色：3F 的水平旋轉決定鏡牆面向陽光的方向；鏡牆的外傾則控制反射光向下進入泳池的角度。冬季低角度陽光因此有機會被導入池面與室內上部空間，增加泳池的採光以及溫度；夏季則以服務中心本體與屋頂的投影，形成降低西曬與高角度日光進入的遮陽屏障，改善泳池內的悶熱。

這不是在原建築外加上一部機器，而是讓建築本身成為感知季節、引導光線的環境裝置。

光環境策略透過日照分析，以全年日照角度、眩光與熱負荷分析提供科學數據，使建築隨著季節的變化，取得室內舒適的平衡。

02
向雨
向雨而生
讓雨水成為建築可見的循環。

晴天時，傾斜的玻璃屋頂引入天空與日光；雨天時，同一片屋頂則開始收集並展示雨簾。

5° 單坡玻璃屋頂橫跨 29 m，從服務中心側高端 +6.537 m 向泳池遠端低端 +4.000 m 下降。雨水順著坡度匯集，在低端屋簷自然落下，形成一面隨雨勢改變的自然雨簾。

小雨時是細密的水絲，大雨時則成為連續水幕。不使用循環泵浦製造人工水景，而是讓真實天氣成為建築表情的一部分。

雨簾下方設置封閉、可拆洗且與地面逕流隔離的承接溝。屋頂水經過濾網、初期雨水分流、沉砂與過濾後，進入加蓋儲水槽，回收用於 1F 廁所沖洗；超過系統容量的極端雨量則由獨立旁通安全排放。

雨水被看見、被聽見、被收集，
最後被重新使用。
03
向人
向人而開
讓光線串聯視線、動線與彼此。

長邊外牆的材料選擇，在泳池大廳段採安全玻璃，通透的設計無形間拉近泳池內外師生們的距離。服務中心1F/3F則使用清水模，玻璃的輕盈中帶著一份和諧安穩。

樓梯使用強固的雙箱型鋼梯梁，不依附玻璃屋頂承重，中間懸浮平台與完全開放的梯下空間，兼顧安全性也能維持一致的通透風格。

台階沿著玻璃牆而上，將沉重的垂直動線轉化為輕盈的延伸線。在樓梯上，可以同時看見泳池、校園與天空；校園中的人也能透過玻璃感受到室內活力。

微傾斜的屋頂仍採玻璃設計，晴天是一片無邊際的天窗，雨天時落下的雨滴聲也有了畫面。透過鏡面牆的角度控制，在冬天也能把明亮溫暖的陽光引進泳池內。

建築因此不只有空間上的穿透，
更產生光線及視線的交流。
04
向時間
向時間延續
讓回憶延續，新舊並存。

不刻意抹去原建築，不以全新的外殼掩蓋它的歷史。1F 泳池、地基、服務中心仍然是建築的原始架構。新的設計整合男女廁、更衣室以及水處理機房，改善了使用動線也讓管線配置更有效率。2F更衣室的觀景窗、水平旋轉的3F鏡面牆、單傾式玻璃屋頂，成為原建築上有趣的新亮點。

新與舊不必互相偽裝，而是能被清楚辨認、又能相互融合。這是一種克制的改建態度，不追求改變得最多，而是讓不變因為改變而更亮眼。

當陽光移動、雨水落下、人在玻璃樓梯間往返，
新舊建築不再只是並置，將在未來的時空中繼續對話。
設計細節
雙角度分工

25.5° 負責平面方向，23° 負責向下導光，讓每個造型動作都有清楚任務。

局部鏡面

鏡面牆映照天空、樹影、水光與校園活動，也降低建築本體的沉重感。

真正的雨景

被動雨簾只在降雨時出現，不以泵浦循環製造水景，讓天氣本身成為建築的一部分。

安全的水路

封閉承接溝、初雨分流、過濾、儲存與極端雨量旁通，兼顧景觀效果、使用安全與水資源回收。

輕盈而獨立的樓梯

獨立不依附玻璃承重的雙箱型鋼梯梁、搭配兩段式懸浮平台，傳遞輕盈的線條延伸感又不失安全性。

通透與隱私並存

公共樓梯廊與泳池大廳保持開放，2F更衣空間則在抵達後立即分流。

整合式的服務中心

服務中心整合男女廁，泳池側與操場側各自獨立互不穿越，乾濕分流方便衛生清潔也讓動線更明確。乾式儲藏、水處理機房與受管制藥劑獨立隔間與進出口，提高管理的安全界線。

可導入的能源系統

3F 現階段保持低使用密度的設備與維修用途，頂樓配置太陽能板，保留未來擴充的彈性。

可以被驗證的幾何

旋轉、傾斜、屋頂坡度與外挑皆有明確數值，可在後續設計、樣板與施工階段持續校核。

而是讓它重新學會面向陽光、承接雨水、看見校園，
