## 必要行為

頁面與分析只從 active `GEO-0.8.2` 內沿用的 v0.6.7 solar working geometry 取得校址、方位、25 × 8.5 m 池體、L3、鏡牆、屋頂、判讀門檻、能量假設、氣象來源與方法修訂版。不得直接讀 `v050Study`、`geometry.solarReflection` 或另存第二套互動／分析預設。

0.9.0 只重整公開 shell、研究導言、資訊層級與手機版面；互動 runtime 仍由現行 `GEO-0.8.2` 選出的相同 solar 子樹取得上述 v0.6.7 工作基線，不重跑最佳化。新增摘要直接讀取 study owner 模板，不硬編碼第二份技術值。

0.9.1 只補入 ORIGIN 敘事與精簡 3D 資訊架構；日照輸入、最佳化結果、互動控制與本契約的研究基線不變。

- L1／L2 固定，只有 L3 水平旋轉。
- 現行研究基線為 L3 +25.5°、鏡牆外傾 +23.0°；基線鏡牆法線由 `127° + 25.5°` 即時計算為 152.5°，不是固定基地方位資料。
- 現行分析方法修訂版為 `SOLAR-METHOD-1.0.0`；active 判讀門檻為方位容差 28°、最低向下角 8°。
- active 能量假設為 `ρ=0.75`、`τ=0.60`、日照時段 07:00～17:00，氣象來源為 `SRC-SITE-003`；程式不得提供靜默 fallback。
- 面池承載牆與鏡面覆層共面，不畫成直牆前的獨立斜鏡。
- 以 NOAA 公開近似式依日期、時間、經緯度與 UTC offset 計算太陽高度／方位；平年 365 天、閏年 366 天。
- 年份預設跟隨 Asia/Taipei 今年，可輸入 2000～2100；日期提供每月 1 日、6/21、12/21，時間提供 07:00～18:00。
- 高度角 ≤0°時不畫入射／反射光，也不報告命中。
- 控制器可比較水平 −20°～+40°、外傾 0°～30°，step 0.1°；平面、剖面、法線、診斷與手機預覽同步。
- 單一日期／時間只稱「方向診斷」，不得冒充全年 kWh、眩光或熱效益。
- 頁面摘要明確區分「v0.6.7 研究基線」與「Model 0.9.6 已驗證」，並由 runtime 顯示 active 方法版號、方位／下射門檻、能量假設及 generated analysis 的 `current`／`stale`／`unavailable` 狀態。
- 互動日期、時間、水平旋轉、外傾角與衍生讀值不得在 HTML 寫入第二套初始值；載入時由 Asia/Taipei 現時及 active solar contract 設定。
- 平面圖以池向為中心顯示 active 方位容許扇形，剖面顯示 active 最低下射角參考線；兩者只代表方向代理門檻，不是精確池面落點、反射能量或完整 3D 光線追蹤。
- 平面圖入射光與反射光使用相同色相；入射光為實線、反射光為虛線，兩者都有傳播方向箭頭。反射虛線明列為向下 3D 反射光的水平投影，標註反射方位與向下角，不得暗示光線穿透鏡牆；既有平面圖標題維持不變。
- 平面鏡牆圖層覆蓋入射／反射光，代表性入射點位於鏡牆中心，光線在牆線兩側各保留極短間隙。鏡牆法線使用不同色相與標示。
- 有效反射除了鏡牆正面受光，完整 3D 反射向量還必須位於鏡面正面半空間。未通過時 runtime、池面命中與有限接收面投影一律 fail closed，不繪製反射光。
- 07:00～18:00 是互動方向診斷範圍；active 07:00～17:00 是年度能量時段。18:00 必須明示只供方向診斷、不納入年度能量。

## v0.6.7 沿用的工作能量摘要

使用 8,760 小時 PVGIS TMY、`ρ=0.75`、`τ=0.60`：

- X35：暖季池面新增 0；冷季 +1,036.829 kWh（+0.962%）。
- 上部／屋頂轉向：暖季 289.797 kWh、冷季 4,857.203 kWh。
- X33／35／37／39／41 暖季為 +0.125／0／0／0／0 kWh，冷季為 +1,199.844／+1,036.829／+876.599／+732.206／+596.158 kWh。
- 舊 +26.5°／+3.1°套入現行池體後為暖季 +200.722 kWh，已淘汰。
- 0.6.7 的 Viewer L2 `splitAxisY` 資料修正、非接收面屋簷與約 169.364 m² 高密度屋頂太陽能概念排布不在本次 solar-study 的遮蔭、反射、眩光或發電分析範圍。0.9.6 audit correction 只把既有方法與假設納入 active contract 及擴充後的 `inputHash`，重驗結果不變，不重跑角度最佳化。

頁面須明示 X33 不滿足嚴格暖季零，且 23° 外傾幅度大，必須經結構、構造、固定、維修、材料、眩光、全年 3D 光線追蹤與熱負荷專業驗證。工作 kWh 不是施工性能保證，也不是 lux、水溫或設備節能模擬。

## 方位不變條件

固定建築只讀 `referenceSystem.siteOrientation` 的 SITE +X 真北 307°；面池反方向 127°、SVG transform 與目標方向均由共用方位函式推導。鏡牆法線一律為 `normalize(127° + 當下 L3 水平旋轉角)`，控制器或未來日照研究結論改變水平角時必須同步更新，不得另存 152.5°。世界 transform 與 L3 局部旋轉不得合併或重複套用。

## 驗收

- HTML 不硬編碼互動初始值或鏡牆法線；runtime 從 active solar contract、canonical 基地方位與 active L3 水平角設定。現行基線顯示 +25.5°、+23.0°、衍生法線 152.5°及 +1,036.829 kWh，改動水平控制值時法線讀值須同步改變。
- runtime 顯示 `SOLAR-METHOD-1.0.0`、方位 ±28°、最低下射 8°、`ρ=0.75`、`τ=0.60`、能量時段 07:00～17:00 與 current analysis 狀態；失敗診斷同時列出實際方位偏差／下射角與各自門檻。
- 平面容許扇形、剖面最低下射線、平面入射／反射向量及兩個箭頭在桌面與手機預覽都可見；反射向量維持與入射向量同色且使用虛線，標註「反射方位投影＋向下角」。鏡牆覆蓋光線、入射點與兩側短間隙清楚可辨，鏡牆法線不會被誤認為反射光。
- 回歸測試須包含外傾鏡牆「水平投影看似越過牆線但完整 3D 向量仍在正面」案例，以及偽造背面反射向量不得命中池面的 fail-closed 案例。
- 最新圖面連結指向 `#V067-L1`，不存在 V2.3 current link。
- 8,760 筆 TMY、工作支點及五支點敏感度由測試鎖定。
- 方位環繞、背光、向下角、有限池面、平／閏年及地平線下行為有回歸測試。
- active 門檻變更必須改變分析，legacy 誘餌值不得影響現行結果；方法版號或能量假設變更必須使 solar registry 標成 `stale`。
- 太陽位置須落在已公布 NREL SPA 範例的文件化近似容差內；垂直鏡解析解、固定屋頂接收包含與反射能量上限須有獨立不變條件測試。
- 320 px 以上可操作；920 px 以下 sticky 預覽與完整 SVG 均保留。
- production build 與桌機／手機 smoke 通過。
