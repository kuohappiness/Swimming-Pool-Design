# 主導覽四向專題群組、一頁一名與圖號去版號

狀態：實作中｜下一步：第一個 PR（導覽群組與一頁一名）待審；第二個 PR 做圖號去版號｜等誰：使用者

- 日期：2026-11-22
- 類型：feat
- 任務：TASK-130
- 決策：[DEC-170](../decisions.md)
- 核准：使用者 2026-11-22 在設計架構審查確認 D1（主導覽五項加四向專題群組）與方案 A（一頁一名、圖號去版號）

來自：[設計架構決定落檔](2026-11-22-design-architecture-decisions.md) 的後續任務表；方案原文見「整體設計架構審查與改善方案」〈改善方案 A：目標網站架構〉。

## 目的

DEC-170 定了主導覽「設計理念｜四向專題｜圖面｜3D｜關於」，但網站仍把每一頁平鋪在主導覽上，新增的水循環、一堂游泳課、設計歷程會讓主導覽擠成八項，手機放不下。同一頁也有好幾個名字（圖面設計、建築圖冊、空間參照圖集；3D 展示、走入建築），瀏覽器分頁標題和導覽用不同的字。圖號 `V067-L1` 帶著早已不是現行的版號，連結一換版就失效。

## 範圍

第一個 PR（導覽群組與一頁一名）：

- `web/src/app/router.ts`：新增 `navigationGroups`（`topics`＝四向專題）與 `group` 欄位；`navigationItems()` 把同群組的頁面合成一項，出現在該群組第一頁的位置；拿掉與頁名不同的 `title`，頁名只有 `label`。
- `web/src/app/app-shell.ts`：主導覽由 `navigationItems()` 產生；群組內的頁面在頁首多一列第二層頁籤；瀏覽器分頁標題改為 `<頁名>｜實小泳池改建概念設計`。
- `web/src/design-system/`：第二層頁籤樣式；`--site-subnav-height`，群組內頁面的 `--site-header-height` 自動加上它，各頁的捲動偏移不用改。
- 頁名：「圖面設計」改「圖面」、「3D 展示」改「3D」；關於頁、README 與 3D 頁的「開啟圖面」連結同步。
- 文件：架構第 5 節（導覽群組）、第 6 節名詞對照的停用舊稱。
- 測試：e2e 主導覽五項、群組 `aria-current`、第二層頁籤位置與 44 px 點擊範圍、分頁標題。

第二個 PR（圖號去版號）：

- 圖號 `REF-001`、`V067-L1`、`V067-L2`、`V067-L3`、`V067-SECTION` 改為 `SITE`、`L1`、`L2`、`L3`、`SECTION`；舊的 `#REF-001`、`#V067-*` 錨點轉到新圖號。
- 圖名去掉「v0.6.7｜」與「最新」。
- 3D 頁、日照研究頁與設計理念頁指到圖面的連結改用新錨點。

不做：水循環、一堂游泳課、設計歷程三頁（新增主題串，頁面進登錄表時帶 `group: 'topics'`）；上一章／下一章、首頁「看證據」連結與兩層用語（另排）；721～900 px 頁首實際兩列高度與 `--site-header-height` 76 px 不一致的既有問題（樣式範圍）。

## 驗收

- 每一頁主導覽都是五項；在日照研究頁，「四向專題」標 `aria-current="true"`，第二層頁籤的日照研究標 `aria-current="page"`；其他頁沒有第二層頁籤。
- 第二層頁籤在頁首內、點擊範圍至少 44 px；群組內頁面的 `--site-header-height` 與頁首實際高度一致（721～900 px 除外，見上）。
- 瀏覽器分頁標題是 `<頁名>｜實小泳池改建概念設計`。
- 介面、README 與架構文件不再用「圖面設計」「3D 展示」指稱頁面。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過；桌機與手機截圖已看過。
