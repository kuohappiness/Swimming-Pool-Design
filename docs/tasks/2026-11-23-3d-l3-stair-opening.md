# 3D 跟上 3F 樓梯口

- 日期：2026-11-23

- 決策：[DEC-174](../decisions.md)、[DEC-175](../decisions.md)

來自：[ST-02 級高與 3F 樓梯口](2026-11-23-st-02-riser-and-opening.md)（TASK-132）：模型 0.12.0 加了樓梯口 `OP-L3-ST-02-01`，3D 要跟上

## 目的

DEC-174 在 ST-02 穿過 3F 的地方開了樓梯口，模型、驗證與圖面都已更新；3D 的 ST-02 也已改成 12＋11 兩跑，但 2F 天花與旋轉的 3F 樓板還是整片，壓在樓梯上方：靠近頂端的踏面離板底只剩幾十公分，端牆也還整道立在樓梯上方。樓梯口切掉了到達翼貼著端牆的那一段，教室入口由 DEC-175（[3F 教室入口](2026-11-23-l3-entry-door.md)，TASK-133）改到樓梯口北側，3D 的門已跟著移過去。

## 範圍

- 網站模型：`core/viewer/viewer-data.mjs` 帶出 `l3.stairOpening`；`model-adapter.ts` 檢查樓梯口在 ST-02 正上方、一路開到樓梯頂端、切開 2F 天花、3F 樓板與到達翼，除樓梯頂端外三邊設欄杆，不符就不畫。
- 開口（`web/src/views/3d-viewer/l3-stair-opening.ts`）：樓梯口是 SITE 矩形、3F 樓板是旋轉的，被切的面先轉成 SITE 的凸多邊形、減掉樓梯口拆成幾塊，再轉回各自的座標拼成一塊；接縫兩邊共用頂點、側面只畫外緣，清水模的稜線不會畫在接縫上。
  - 2F 天花 `CLG-L2-01`、旋轉的 3F 樓板，以及不旋轉的擴板、景觀區與到達翼地面，在樓梯口範圍開口；到達翼的屋頂不切。
  - 3F 端牆斜斜跨過樓梯口，那一段下面沒有樓板、也會擋住樓梯的淨高，只留到達翼屋頂（+2.85 m）以上的一段。
  - 防墜欄杆：照 DEC-175，除了樓梯頂端接到達翼平台的 X39.5 那一邊，Y0.5、Y2.0、X34.85 三邊全長都設；欄杆跨過旋轉的教室與不旋轉的到達翼，畫在 SITE 座標。安全玻璃欄板加頂端扶手與兩端立柱，高度沿用 3D 景觀區欄杆的 1.15 m 當示意。欄杆可點選，顯示 `OP-L3-ST-02-01` 的說明。
- 教室（`l3-learning-room.ts`）：教室的地面範圍扣掉樓梯口；桌椅整組往鏡牆移 1 m，留在樓梯口西側；說明加上淨面積 59.739 m²。入口門照 TASK-133 畫在 `learningRoom.entryDoor` 那一段端牆。
- 3D 契約：2F 天花的開口、樓梯口與欄杆寫進契約。

不做：

- 漫遊時 3F 樓梯口上方仍走得過去（3F 的牆、玻璃與欄杆本來就沒有碰撞）。
- 樓梯口邊梁、旋轉樓板被切角後的結構、欄杆的實際高度與構造、防火區劃（`OPEN-019`）。

## 驗收

- ST-02 每一級踏面外緣（梯梁內側的走行範圍）往上到第一個構件的淨高都不小於 1.90 m；樓梯口以西的淨高就是 2F 天花板底。
- 從樓梯口上方往下看，第一個碰到的是樓梯，不是天花、樓板或到達翼的地面；樓梯口外的 3F 樓板與到達翼地面還在。
- 切開後的面積和模型一致：3F 樓板 162 − 6.261 m²、到達翼可走 2.25 m²、擴板 6.935 − 0.714 m²、教室淨 59.739 m²；拼起來的樓板每條邊剛好被兩個三角形共用，稜線只出現在外框與樓梯口的邊。
- 從教室往樓梯口走，Y2.0、X34.85、Y0.5 三邊都先碰到欄杆；兩條長邊一路到樓梯頂端 X39.5，頂端那一邊沒有欄杆；端牆在樓梯口那一段沒有牆也沒有門、到達翼屋頂以上有牆；教室門在 `entryDoor` 那一段端牆；桌椅離樓梯口邊至少 0.6 m（單元測試，合併前後的場景都測）。
- 網站模型的樓梯口不符 DEC-174 時拒畫。
- 繪製呼叫不超過 `core/viewer/render-budgets.mjs` 的上限。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過。

## 需要使用者確認

- 欄杆 1.15 m 是沿用 3D 景觀區欄杆的示意高度，實際高度與構造待 `OPEN-019`。
