# 關於頁

狀態：已合併｜完成：新增「關於」分頁：作者、資料來源與授權、28 條名詞、11 題常見問題與四張圖面下載，主導覽變成五項｜等誰：—

來自：[DEC-152](../decisions.md)、[新增網站主題方案](https://claude.ai/artifact/TGHTXewPyKNWHZsdpxS6g4)〈各主題內容規劃〉的「關於與資料」

## 目的

網站原本沒有任何一頁說明誰做的、資料從哪裡來、頁面上的名詞與狀態是什麼意思。讀者是校內師生與家長，但頁面直接出現 SITE-XY、TMY、MODEL、GEO 等術語，也沒有地方回答「這會不會蓋」「鏡牆會不會刺眼」這類最常被問的問題。不做的話，後續三個專題頁（設計歷程、水循環研究、一堂游泳課）的名詞與來源也沒有共同的落點。

## 範圍

- 新增 view `about`，導覽標籤「關於」，網址 `?view=about`，排在主導覽最後一項。
- 文案放 `content/about.md`，分六節：關於這個專案、怎麼讀網站上的數字、資料來源與授權、名詞解釋（28 條）、常見問題（11 題）、下載與版本。
- `tools/build/build-content.mjs` 新增 `compileSectionedContent`：以 `<!-- section:id -->` 分節，每節一個二級標題，三級標題各成一個項目，數值一律用模型 token；產物 `web/src/generated/about-content.json`。
- 頁面 `web/src/views/about/`：頁內目錄、名詞表（`dl`）、常見問題（原生 `details`，可用鍵盤操作，可由 `#about-faq-<n>` 直接開啟）、四張現行圖面的 SVG 下載。
- 主導覽由四項變五項：導覽欄改為依項目數自動排列；手機寬度縮小左右間距，並在載入時把目前頁面的標籤捲進可視範圍。
- `tools/build/build-copy.mjs` 納入關於頁（擷取前展開所有問答），重新產生 `content/website-copy.md`。

不在範圍：

- 作者介紹只寫現有頁尾已公開的姓名，協助者、製作工具的細節與回饋管道等使用者提供文字後再補。
- 主導覽的分組（四向專題）與手機展開面板屬於整體導覽與樣式方案。
- 文案如實寫出尚未分析的項目（眩光、夏季得熱、無障礙）。設計理念頁既有文字與此不一致之處，由資料正確性的工作處理，本任務不改其他頁的文案。

## 驗收

- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過。
- 單元測試：分節編譯的切分、token 帶入、缺節／多節／順序錯誤／重複／無標題／空項目都會擋下；關於頁文案不含手寫的長度數值，連結只指向站內分頁或本 repo。
- 瀏覽器測試：五個分頁在五種寬度下導覽為五項且不溢出、目前頁面的標籤在可視範圍內；關於頁六節與目錄一致、外部連結另開視窗、問答可用滑鼠與鍵盤展開、深連結會展開並捲到該題、四張圖面可下載且內容為 SVG、可點目標高度不小於 44 px。
- 桌機與手機截圖附在 PR。
