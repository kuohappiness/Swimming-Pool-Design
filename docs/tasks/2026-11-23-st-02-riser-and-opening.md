# ST-02 級高與 3F 樓梯口

狀態：已合併｜完成：ST-02 改為 23 級（12＋11），級高約 15.6 cm 符合第 33 條第一欄；2F 天花與 3F 樓板補上樓梯口，教室淨 59.739 m²；寫進模型 0.12.0，驗證、圖面、合規對照與文案同步；發布紀錄 0.12.0｜等誰：—

- 日期：2026-11-23
- 類型：feat
- 任務：TASK-132
- 決策：[DEC-174](../decisions.md)

來自：[3F 觀課與環境教育室](2026-11-23-l3-learning-room.md) 的「不做」項目；方案文件〈ST-02 樓梯級高改善方案（TASK-132）〉

## 目的

ST-02 原本 22 級、每級約 16.27 cm，超過建築技術規則設計施工編第 33 條第一欄（小學校舍等供兒童使用之樓梯）16 cm 的上限，網站在〈尚未完成的專業檢核〉揭露這一條。3F 有學生小組使用後要改。檢查時另外發現整座樓梯都在旋轉 L3 樓板下方，從 X34.7 起踏面到板底的淨高不到第 35 條的 1.90 m，但模型、圖面與 3D 都沒有樓梯口，3F 教室的 66 m² 也沒有扣掉它。

## 範圍

- 決定：新增 DEC-174；OPEN-019 註記已畫進模型的部分與仍待確認的項目。
- 共用幾何：新增 `core/geometry/stair-geometry.mjs`，從各跑級數推導跑長、中平台、頂端、踏面外緣、淨高不足的起點，以及矩形與旋轉多邊形的重疊面積；附單元測試。
- 模型：新幾何版本 `GEO-0.12.0`（`GEO-0.11.0` 改成 legacy 指標）。`l2.stairToL3` 改 23 級，`risersPerRun`、`treadsPerRun`、`runLengths` 改為兩個元素的陣列，加 `midLandingElevation`；新增 `l3.stairOpening`（`OP-L3-ST-02-01`，X34.85～X39.5／Y0.5～Y2.0）；`l3.learningRoom` 加 `netArea`、`stairOpeningOverlapArea`，`l3.arrivalWing` 加 `walkableArea`。
- 驗證：級高 ≤ 0.16 m、級深 ≥ 0.26 m、跑長與中平台高程符合級數、兩個平台 1.50 m、樓梯口從淨高不足處起到頂端、樓梯口切到的構件與欄杆、教室與到達翼扣掉的面積，並附反例測試。
- 圖面：2F 平面圖的踏面線、級數與上方樓梯口；3F 平面圖的樓梯口、教室側欄杆與教室淨面積；剖面圖的中平台高程與樓板開口。四張圖以 `GEO-0.12.0` 重產。
- 3D 最小相容：viewer 資料改給兩跑各自的長度，ST-02 的踏步、梯梁與漫遊坡度照兩跑不等長畫；樓板開口與教室欄杆交給 3D 串。
- 文件：合規對照 CMP-06、07、09 更新並新增 CMP-19（第 35 條淨高）、設計基準、模型與 3D 契約、圖面說明、設計理念頁移除「3F 樓梯級高」揭露。

不做：3D 的樓板開口與欄杆（交給 3D 串）、欄杆高度與形式、樓梯口邊梁尺寸（待專業確認）。

## 驗收

- `npm run check:model` 通過；反例測試涵蓋改回 22 級、跑長不符級數、樓梯口起點太晚、樓梯口沒到頂端、教室與到達翼沒扣面積、沒有欄杆。
- 合規對照測試依模型算出 CMP-06、07、09、19，四列都是「符合」。
- 2F、3F 平面圖與剖面圖看得到 23 級與樓梯口；1F 平面圖只有版本字樣變動。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過。

## 結果

- 23 級：R 0.155652 m、T 0.261905 m、第一跑 2.881 m（12 級）、中平台 +5.168 m、第二跑 2.619 m（11 級），頂端 X39.5；每跑高度 1.868／1.712 m。
- 樓梯口 6.975 m²：6.261 m² 在教室內（教室淨 59.739 m²），0.714 m² 在到達翼內（可走 2.25 m²）。樓梯口外最小淨高 1.939 m，以 2F 天花板底 +6.64 m 計；邊梁的梁底高度確定後要重算。
- 版本升為 0.12.0（新幾何必須搭配新模型版本）；發布紀錄見 [0.12.0](../releases/0.12.0.md)。
