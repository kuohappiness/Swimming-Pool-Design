- 決策：[DEC-159](../decisions.md)、[DEC-170](../decisions.md)、[DEC-171](../decisions.md)、[DEC-172](../decisions.md)

來自：[設計架構決定落檔](2026-11-22-design-architecture-decisions.md) 的後續任務表

## 目的

DEC-159、DEC-170～172 只寫在決定表時，公開網站仍在說「保留 1F 泳池、地基」、把專案叫「翻修」、說鏡牆把「溫暖」的陽光引進來、說 3F 是「低使用密度的設備與維修用途」；TASK-118 已把入口坡道、無障礙暨親子室、救生椅、AED 與管理暨急救室做進模型，但〈尚未完成的專業檢核〉還把它們列為沒處理。不改的話，網站說的話和決定、模型不一致。

## 範圍

- 「保留」只指位置與校園記憶（DEC-159）：`content/design-concept.md`〈設計從保留開始〉與〈向時間延續〉；日照研究頁「L1／L2 是不可變的基準」拿掉「地基」。
- 專案名稱統一為「改建」（DEC-170）：網站標題與頁首、`web/index.html` 的 title 與 description、模型 `project.name`、README、`docs/product.md`、`docs/site-and-sources.md`、圖面標題欄。
- 鏡牆不稱增溫或節能、能源主角是屋頂光電（DEC-171）：〈向光〉冬季陽光一句、〈可導入的能源系統〉。
- 3F 本期納入教師觀課與環境教育（DEC-172）：〈可導入的能源系統〉改寫；位置、面積與到達方式留給 TASK-131，不改模型。
- 依 TASK-118 新增〈一堂課的動線〉，並更新〈整合式的服務中心〉（取消乾式儲藏，加入無障礙暨親子室、管理暨急救室、救生椅、AED）。
- 〈尚未完成的專業檢核〉：移除入口高差、無障礙廁所與浴室、救生配置三條，改為一句「已加入、待專業覆核」；池深一條補上教學平台 0.80 m；2F／3F 無障礙通路與 3F 樓梯級高保留。
- 重產 `content/website-copy.md` 與四張圖面。

不做：〈關於〉頁的「翻修」（新增主題串 PR #11 擁有該檔）、導覽與圖號（TASK-130）、3F 提案與模型（TASK-131）、決定表與封存文件中的歷史用語。

## 驗收

- 現行公開文案、網站標題、模型名稱與圖面標題沒有「翻修」；沒有「保留地基」「保留池體」或鏡牆增溫、節能的說法。
- 〈一堂課的動線〉與〈整合式的服務中心〉的每一句都對得上 `l1.poolUse` 的項目。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過；設計理念頁桌機與手機截圖已看過。

## 結果

- 四張圖面標題欄由「翻修」改為「改建」，幾何沒有變。
- 順手修正：TASK-118 重產的平面圖把真北說明寫成英文 `lower-right`，圖面頁的替換規則因此對不上。方位的中文說明改由 `core/geometry/site-orientation.mjs` 的 `NORTH_PLAN_DIRECTION_LABELS` 提供，圖面產生器與圖面頁共用，圖面測試加上中文說明的斷言。
- `content/about.md` 的「翻修」由新增主題串在 PR #11 一併改寫。
- 3F 的位置、面積與到達方式仍待 TASK-131 提案；模型與驗證仍照 `DEC-097` 的現行幾何。
