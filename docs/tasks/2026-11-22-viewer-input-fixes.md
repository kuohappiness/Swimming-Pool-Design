## 範圍

| 錯誤 | 原因 | 修法 |
| --- | --- | --- |
| 畫面正中央點不到構件 | 射線先打到屋頂上隱藏的邊線 `visual-only:frame-edge`，它沒有所屬構件，舊邏輯也不排除隱藏物件 | 略過隱藏物件，命中細部時沿父層找所屬構件，邊線容差由 1 m 降到 2 cm |
| 拖曳旋轉放開後誤選 | 放開就當點選 | 按下到放開移動超過 6 px 不算點選 |
| 關掉的圖層仍可點選 | 未排除隱藏物件 | 只選可見物件 |
| 「尚待確認」連結失效 | 指向公開站上不存在的 `docs/backlog.md` | 改連 GitHub 上的 `docs/backlog.md` |
| 漫遊時下拉選單與按鈕的按鍵無效 | 視窗層級攔截所有移動鍵 | 焦點在輸入框或下拉選單時交給它們；在按鈕或連結時保留空白鍵與 Enter |
| Ctrl 下潛觸發瀏覽器快捷鍵 | 下潛綁 Ctrl 與 C | 下潛只用 C；帶 Ctrl、Cmd、Alt 的按鍵交給瀏覽器 |
| 高更新率螢幕丟失視角輸入 | 視角跟著物理步套用，沒有物理步的畫面輸入被丟棄 | 視角每個畫面套用一次，移動仍走固定步長 |

不在範圍：不支援 WebGL 時的說明文字（方案第 10 項）由 3D 展示工作決定呈現方式。

## 驗收
