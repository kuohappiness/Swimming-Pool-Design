# 樣式外框與手機：頁首選單、頁尾、頁面首區、標題字級、列印與網站圖示

狀態：已合併｜完成：900px 以下單列頁首加原生選單面板、版號移到頁尾技術資料、頁尾上一章下一章、標題字級變數、全站列印樣式、網站圖示與分享圖｜等誰：—

- 任務：TASK-172
- 決策：[DEC-212](../decisions.md)
- 核准：使用者 2026-11-23 在討論串說「繼續」，開始樣式階段三
- 前一步：[樣式可讀性](2026-11-23-style-readability.md)（TASK-171），本任務疊在它之上

來自：[網頁樣式審查與改善方案](https://claude.ai/artifact/WTV9jhHer5b5eiMjk3GBDj)〈實作順序〉階段三，處理問題 H9、M1、M2、M8、M11、M12

## 目的

審查時量到：900px 以下頁首排成兩列共 116px 並固定在頂端，橫向手機佔去畫面近四分之一，320px 寬時第四個導覽項目被裁掉；每頁最上面都印著 `MODEL 0.10.0` 這類內部代碼；首頁 H1「重新定向」55px，章節 H2「向光」86px，標題大小與層級相反；各頁首區的排法與留白不一樣；列印時導覽照印、圖片跨頁切斷；網站沒有圖示，分享到通訊軟體沒有預覽圖。

## 範圍

頁首（H9、M8）：

- 900px 以下頁首改為單列 56px：校徽、站名、「選單」鈕。主導覽收進選單面板，面板用瀏覽器原生的 popover，按 Esc 或點面板外就關、焦點回到選單鈕，不另寫程式。群組頁的第二層頁籤仍留在頁首下方（群組頁 101px）。
- 桌機維持單列，主導覽置中。
- 頁首右側的 `MODEL` 版號拿掉，移到頁尾收合的「技術資料」。

頁尾：

- 新增上一章、下一章，依路由登錄表的頁序，第一頁沒有上一章、最後一頁沒有下一章。
- 版號、幾何版次、座標系與單位收進「技術資料」展開區，列印時展開。

頁面首區與標題字級（M1、M2）：

- 新增標題字級變數：`--site-text-h3`（24px）、`--site-text-h2`（28 到 40px）、`--site-text-h1`（32 到 56px）、`--site-text-display`（40 到 72px，只給首頁 H1）。
- 各頁首區（英文小標、副標、H1、導言）一律一欄由上而下，留白一致；拿掉圖面頁的兩欄排法，以及關於、設計歷程、圖面三頁各自的留白。
- 每頁 H1 是該頁最大的字：首頁 H1 改用展示級，章節側標題（向光、向雨⋯）、設計細節、結語與頁末的大標題降到 H1 級以下；首頁、日照研究、設計歷程、關於的 H2 一律用章標級。

列印（M11）：

- 新增 `web/src/design-system/print.css`：頁首、選單與上一章下一章不印；標題不留在頁底；圖、表、照片與引文不跨頁切斷；技術資料展開印出。
- 首頁取消捲動敘事的滿版高度與固定定位，四個設計方向各從新的一頁開始，方向索引與頁末連結不印。
- 圖面頁整份 A4 橫印，圖紙與資訊列收在同一頁，首區與頁尾不印。

網站圖示與分享預覽圖（M12）：

- 新增 `npm run build:icons`（`tools/build/build-icons.mjs`）：從校徽原始檔與網站字型以 Chrome 繪出 `favicon-32.png`、`apple-touch-icon.png`（180 × 180）、`share-card.png`（1200 × 630），放在 `web/public/`，建置時原樣複製到網站根目錄。需要瀏覽器，所以不在 `npm run build` 裡，產物入庫。
- `index.html` 加上網站圖示與社群分享的 `og:*` 標記；爬蟲不認相對網址，分享圖寫公開網址。

不做（之後再做）：

- 3D 頁的樣式檔一行未動。3D 頁首區仍是兩欄，等 3D 介面改版時改用共用首區並縮短（方案〈3D 展示〉）；頁首在漫遊時不佔位也由那時處理。
- 首頁章節的結構（每章兩個 H2：側標題與內文的同名標題）屬階段四的首頁重排；這一步只先讓字級順序正確。日照頁圖卡的 H2（20px）也等階段四日照頁重排時改成 H3。
- 橫向手機頁首不固定：改成單列 56px 後只佔橫向手機畫面的 14%（群組頁 26%），未超過方案訂的三成，所以維持固定，避免各頁 sticky 元素要再分兩套偏移。
- 頁尾日期改由發佈資料帶入：目前沒有可帶入的發佈日期欄位，屬資料正確性範圍。頁尾聲明行等使用者與資料正確性串定文字（DEC-156 之後再決定），不先放佔位字。
- 校徽小檔：TASK-161 已改為 96px WebP。

## 驗收

- 900px 以下：選單鈕至少 44px、打開後五個主導覽項目都在畫面內且至少 44px、Esc 關閉；頁首實際高度等於 `--site-header-height`（一般頁 56px、群組頁 101px）。
- 每頁頁尾的上一章、下一章符合登錄表順序，點擊範圍至少 44px。
- 每頁 H1 是該頁最大的字（3D 頁除外，見〈不做〉）。
- 列印：圖面頁一張圖紙一頁；首頁的照片與圖不被切斷。
- 網站圖示、分享圖在建置產物裡可取得。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過；瀏覽器測試涵蓋選單、頁尾上一章下一章與網站圖示。

## 結果

2026-11-23，雲端環境（Chromium），與 TASK-171 的建置比對：

- 頁首：900px 以下由 116px（群組頁 161px）降為 56px（群組頁 101px）；320 到 900px 選單面板五項都在畫面內、點擊範圍 52px。
- 標題：每頁 H1 都是該頁最大的字，桌機 56px、首頁 72px；首頁章節側標題由 77px 降為 56px，各頁 H2 統一為 40px（手機 28px）。
- 列印（A4）：圖面頁由 2 頁（圖紙與頁尾分開）變成 1 頁橫印；首頁四個設計方向各從新的一頁開始，照片與圖不再被切斷，總頁數由 11 頁變 12 頁。
- axe 對比與小於 12px 的文字：六頁在 1440 與 390 寬與改動前相同（四頁 0 處；3D 頁維持原狀）。1440 到 320 共 10 種寬度沒有新出現的溢出或裁切。
- 網站圖示與分享圖：三個檔共 98,774 bytes。
