## 目的

原本 `npm run lint` 只跑 ESLint：CSS 沒有任何檢查，刪掉的檔案或套件沒人發現，依賴版本只靠人工更新。這一步先把檢查接上，現有程式不改寫，避免和其他討論串手上的 PR 衝突。

## 範圍

| 工具 | 設定 | 進 CI | 目前結果 |
| --- | --- | --- | --- |
| stylelint | `.stylelintrc.json`：延伸 `stylelint-config-recommended`；關掉 `no-descending-specificity`（76 處，多半是同一檔不同元件的選擇器先後，要改得重排整份 CSS）；重複選擇器與無效屬性值先列為警告 | 是，`npm run lint:css` | 0 錯誤、4 警告 |
| knip | `knip.json`：列出工具、單元測試與 e2e 的入口 | 是，`npm run lint:unused` | 未用檔案、未用套件、未列套件都是 0；未用匯出 89、未用型別 60、重複匯出 2 先不擋，`npx knip --include exports,types,duplicates` 可列出 |
| Prettier | `.prettierrc.json`（單引號、每行 100 字）、`.prettierignore`（文件、模型、圖面、原始來源、產生檔不碰）；`npm run format`、`npm run format:check` | 否 | Prettier 管得到的 187 個檔案有 144 個會被改寫 |
| Dependabot | `.github/dependabot.yml`：npm 每週一（臺北時間）把次要與修補版本合成一個 PR，大版本不提；GitHub Actions 每月一次 | — | — |

`npm run lint` 改為依序跑 ESLint、stylelint、knip，CI 的 Lint 工作不用改設定。方案原列的 `.node-version`、`engines` 與 gitleaks 已在 TASK-111 完成。

警告的處理：

- stylelint 的四處：`3d-viewer/styles.css` 與 `3d-viewer/view.css`、`drawings/view.css` 各有一個重複選擇器；`drawings/styles.css` 的 `.pool-water` 寫成 `fill: url(#water-grid), #a3e2e9;`，多了逗號整行無效。查過 `.pool-water`、`.pool-section` 與 `#water-grid` 花紋都沒有任何畫面在用，是留下來的舊樣式，改了畫面不會變。這些檔案屬網頁樣式串與 3D 串，不在這裡改，已轉告。
- knip 的未用匯出與型別：不少是單元測試經 Vite 載入（`ssrLoadModule`）用到的，knip 看不到；其餘是 `walkthrough/index.ts` 轉出的型別。等階段 5 拆檔時一起清，清完再納入 `npm run lint`。

不做（之後再做）：

- 全庫 Prettier 格式化與 `format:check` 進 CI：其他討論串手上的 PR 都合併、協調者通知後一次做。
- axe 無障礙檢查、改用 `@playwright/test`、單元測試不再各自啟動 Vite、ESLint 型別感知規則：會動到測試與程式結構，和階段 5 一起做（等 3D 寫實升級完成）。
