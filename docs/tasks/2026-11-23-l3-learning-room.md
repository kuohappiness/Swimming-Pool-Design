# 3F 觀課與環境教育室

狀態：已合併｜完成：3F 分為 66 m² 觀課與環境教育室與 96 m² 設備區並以隔音玻璃分隔，寫進模型 0.11.0，驗證、3F 平面圖與文案同步；發布紀錄 0.11.0｜等誰：—

- 日期：2026-11-23
- 類型：feat
- 任務：TASK-131
- 決策：[DEC-172](../decisions.md)、[DEC-173](../decisions.md)
- 核准：使用者 2026-11-23 在決定卡選「小組，鏡牆不動只用攝影機」

來自：[設計架構決定落檔](2026-11-22-design-architecture-decisions.md) 的後續任務表

## 目的

DEC-172 決定 3F 本期要有人使用，但位置、面積與到達方式沒有定，模型與驗證仍照 DEC-097 的「本期不設」，網站也只能寫「仍在規劃」。這個任務把使用者選定的分區與使用方式寫進唯一模型，讓驗證、圖面與文案從同一份資料長出來。

## 範圍

- 決定：新增 DEC-173；DEC-097 的「本期不設」標為由 DEC-172／DEC-173 取代，禁止移到 3F 的清單保留；OPEN-009 加註人數與樓梯。
- 模型：新幾何版本 `GEO-0.11.0`（`GEO-0.10.0` 改成 legacy 指標）。`l3.learningRoom`（`Z-L3-LEARN-01`，旋轉前 X29～X41／Y0～Y5.5，66 m²）、`l3.equipmentZone`（`Z-L3-MEP-01`，Y5.5～Y13.5，96 m²）、`l3.glassPartition`（`W-L3-GLASS-01`，隔音玻璃與上鎖維修門），三者與 L3 共用 +25.5° 旋轉；`l3.programStrategy` 寫入使用者、不作整班、攝影機觀課、鏡牆不開窗與 1F 看板；`program.l3` 同步。
- 驗證：`core/validation/model-validation.mjs` 檢查分區面積相加等於 162 m²、教室由到達翼進入、設備區只給維修人員、玻璃隔間有上鎖門、不作整班、鏡牆不開窗也不改材質，並附反例測試。
- 圖面：3F 平面圖畫出兩區、玻璃隔間與說明；四張圖以 `GEO-0.11.0` 重產。
- 文件：設計基準、模型與 3D 契約的版本字樣、圖面說明、設計理念頁〈可導入的能源系統〉與〈尚未完成的專業檢核〉。

不做：3D 的 3F 室內（交給 3D 串）、ST-02 級高改到 16 cm 以下（另開 TASK-132）、攝影機與看板的設備規格、人數上限與電梯（待專業確認）。

## 驗收

- `npm run check:model` 通過；反例測試涵蓋整班使用、鏡牆開口、鏡牆改材質、教室面積、教室入口、設備區開放、維修門未上鎖與玻璃隔間位置。
- 3F 平面圖看得到兩區、玻璃隔間與 DEC-173 說明，其他三張圖只有版本字樣變動。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過；設計理念頁與 3F 平面圖截圖已看過。

## 結果

- 鏡牆改反射玻璃的評估：以 `SOLAR-METHOD-1.1.0` 分段計算，旋轉前 Y0～Y5.5 那段鏡牆貢獻涼季池面增量的 90%，換成反射率 0.3～0.5 會少 30%～54%，因此不採用；日照輸入沒有改，`solar inputHash` 不變。
- 3F 的人數上限、是否需要第二座直通樓梯或電梯、懸挑角活載、隔音等級與攝影機位置仍待專業確認（`OPEN-009`）。
- 版本升為 0.11.0（新幾何必須搭配新模型版本）；發布紀錄見 [0.11.0](../releases/0.11.0.md)。
