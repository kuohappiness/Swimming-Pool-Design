# 水循環頁

狀態：已合併｜完成：新增「水循環」分頁：臺中月雨量圖表、落在玻璃屋頂上的雨水概念估算、雨水的八站路徑與待解問題，雨量取自中央氣象署並登錄為 SRC-DATA-001｜等誰：—

來自：[DEC-152](../decisions.md)、[DEC-181](../decisions.md)、[新增網站主題方案](https://claude.ai/artifact/TGHTXewPyKNWHZsdpxS6g4)〈各主題內容規劃〉的「水循環研究」

- 任務：TASK-141
- 核准：使用者 2026-11-22 在方案的決定卡選擇「四頁全做」

## 目的

網站的四個敘事方向裡，「向雨」只有設計理念的一段文字：雨簾、承接溝、回收沖廁。讀者看不到臺中一年下多少雨、屋頂接得到多少、雨水依序經過哪些地方，也看不出哪些已經決定、哪些還沒有算。不做的話，「讓雨水成為可見的循環」只是一句話，沒有任何數字或流程可以檢驗。

## 範圍

- 新增 view `water-cycle`，頁名「水循環」，網址 `?view=water-cycle`，登錄在四向專題群組（`group: 'topics'`，DEC-170），第二層頁籤排在日照研究之後。
- 登錄第一筆公開統計資料 `SRC-DATA-001`（中央氣象署臺中氣象站 1991～2020 月平均降水量），放 `source-materials/data/`，並寫進模型 `sources` 與[基地與來源](../site-and-sources.md)。
- 新增 `core/water/roof-rainfall.mjs`：雨量乘上屋頂水平投影面積，得到每月與全年落在屋頂上的雨水、暖季與冷季的分配、最多與最少的月份，以及測站到校址的距離。
- `tools/build/build-content.mjs` 新增 `{{data:<欄位>|<格式>}}` 與毫米、平方公尺、立方公尺、公里、百分比等格式；建置時把換算結果寫到 `web/src/generated/water-cycle-data.json` 給圖表用。
- 文案放 `content/water-cycle.md`，分六節：開場、臺中一年下多少雨、玻璃屋頂接得到多少雨、一滴雨的路（八站，照 DEC-036）、雨太多和雨太少的時候、還沒有答案的問題（OPEN-014）。
- 月雨量畫成單一數列的長條圖：只用一條座標軸、只標最多與最少的月份、滑鼠移上去或手指點一下顯示該月數值，圖下方有同一份數字的表格。
- `tools/build/build-copy.mjs` 納入水循環頁；網站文字快照 `content/website-copy.md` 由下一次發版重產（DEC-200）。

不在範圍：

- 不估可回收的水量、儲水槽容量、沖廁用水量與自來水替代率。逕流係數、初雨分流量、使用人數與天數都沒有設計值，仍由 OPEN-014 管理；有答案後再加情境比較。
- 不引用降水日數。來源表格沒有寫降水日的門檻，資料已登錄但確認前不上網頁。
- 不另嵌 3D 畫面，雨天的樣子連到 3D 頁的雨天場景（`?view=3d-viewer#rain`）。
- 三樓屋頂與地面的雨水不在這套回收流程內（DEC-036 只收玻璃屋頂的水），本頁不計。
- 關於頁、設計歷程頁與本頁的頁內目錄、分節標題與卡片樣式各寫了一份，尚未抽成共用元件；留給樣式整理的任務一起處理。

## 驗收

- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過。
- 單元測試：一毫米落在一平方公尺是一公升；月份不足十二個、負值、非數字、月份相加與全年值不符都會擋下；`SRC-DATA-001` 的十二個月相加等於全年值；`data` token 沒有提供資料、欄位不存在或型別不對時建置失敗；水循環文案六節齊全、寫出站號與統計期間、不含手寫的帶單位數字；把模型的屋頂加長後水量與頁面內容跟著變。
- 瀏覽器測試：七個分頁在五種寬度下主導覽與四向專題頁籤都不溢出、分頁標題用頁名；水循環頁五節與目錄一致；十二根長條的高度與表格數字成比例、都貼齊基線、寬度不超過 24 px，只有最多與最少的月份有數字標籤；滑鼠移上去出現提示，手機點一下出現、再點一下收起且不超出畫面；表格可用鍵盤展開；外部連結另開視窗；手機寬度下八站改為直排；可點目標不小於 44 px。
- 桌機與手機截圖附在 PR。

## 結果

- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 都通過。
- 新增 9 個單元測試與水循環頁的瀏覽器測試；原有測試只把分頁數由六改成七、四向專題的路由加上本頁，沒有刪除或放寬。
- 模型只在 `sources` 增加一筆來源登錄，幾何與版號不變。
