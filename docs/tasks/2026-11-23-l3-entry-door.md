# 3F 教室入口

狀態：已合併｜完成：到達翼往北延伸到教室端牆中段，教室門開在端牆、避開樓梯口與隔音玻璃，樓梯口除樓梯頂端外四周設欄杆；寫進模型 0.13.0，驗證、3F 平面圖與 3D 相容同步；發布紀錄 0.13.0｜等誰：—

- 日期：2026-11-23
- 類型：fix
- 任務：TASK-133
- 決策：[DEC-175](../decisions.md)
- 核准：使用者 2026-11-23 在決定卡選「到達翼往北延伸，端牆開門」

來自：[ST-02 級高與 3F 樓梯口](2026-11-23-st-02-riser-and-opening.md) 合併後，3D 串畫 3F 教室時發現的問題

## 目的

0.12.0 補上樓梯口 `OP-L3-ST-02-01` 後，到達翼原本貼著教室端牆的那一段（Y0.5～Y2.0）整段落在樓梯口裡，3F 教室沒有可以走進去的門；3F 平面圖的樓梯口南側也沒有畫欄杆，人從樓梯頂端上來時，樓梯口另外兩邊同樣沒有防墜保護。

## 範圍

- 決定：新增 DEC-175；OPEN-019 註記入口位置與仍待確認的項目。
- 模型：新幾何版本 `GEO-0.13.0`（`GEO-0.12.0` 改成 legacy 指標）。`l3.arrivalWing` 的多邊形往北延伸到教室端牆與 Y3.039（教室東北角那條水平線），面積 4.388 m²、可走 3.674 m²；景觀平台扣掉新到達翼後淨 2.547 m²；`l3.learningRoom` 加 `entryDoor`（端牆上 Y2.0 到隔音玻璃面那一段，長 1.081 m）；樓梯口 `edgeProtection` 改為除樓梯頂端外四周欄杆。
- 驗證：到達翼面積由多邊形算出、景觀平台淨面積跟著到達翼、門在教室端牆上且在樓梯口外與隔音玻璃前、門段長度相符、欄杆範圍，並附反例測試。
- 圖面：3F 平面圖畫出延伸後的到達翼、教室門與動線箭頭、樓梯口三面欄杆，景觀平台標示移位。四張圖以 `GEO-0.13.0` 重產。
- 3D 最小相容：教室端牆的門改讀 `learningRoom.entryDoor`；漫遊時 ST-02 上平台北側拿掉碰撞牆，從樓梯頂端可以往北走到門口；景觀平台的上鎖門與盆栽移到延伸後的到達翼外，避免擋住新到達翼。

不做：3D 的教室門扇、樓梯口欄杆（交給 3D 串）；門寬、開門方向、防火門等級與無障礙淨寬（待專業確認）。

## 驗收

- `npm run check:model` 通過；反例測試涵蓋門段放回 0.12.0 的接觸段（整段在樓梯口內）、門段伸進隔音玻璃、門段長度不符、景觀平台面積沒跟著改、樓梯口沒有欄杆。
- 3F 平面圖看得到延伸後的到達翼、教室門與樓梯口三面欄杆；其他三張圖只有版本字樣變動。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過。

## 結果

- 到達翼：X38.666～X41／Y0.5～Y3.039 的五邊形，4.388 m²（原 2.964 m²），扣掉樓梯口 0.714 m² 後可走 3.674 m²；延伸的部分取自原本 6.935 m² 的正交延伸範圍（景觀平台讓出），L3 總面積不變、仍全在 L2 投影內。
- 教室門：端牆 Y2.0（X39.382）到隔音玻璃面（X39.847／Y2.976），長 1.081 m，可放 0.9 m 門；教室淨面積 59.739 m² 不變。
- 景觀平台淨 2.547 m²（原 3.971 m²）。
- 版本升為 0.13.0；發布紀錄見 [0.13.0](../releases/0.13.0.md)。
