# 3D 的 3F 觀課與環境教育室

狀態：已合併｜完成：3F 分成觀課與環境教育室和設備區畫進 3D：隔音玻璃與上鎖維修門、兩區範圍、螢幕看板與 15 個座位的桌椅，水塔與設備隨 3F 樓板旋轉留在玻璃後（PR #47）｜等誰：—

- 日期：2026-11-23
- 類型：feat
- 任務：TASK-153
- 決策：[DEC-173](../decisions.md)
- 契約：[3D 展示契約](../contracts/3d-viewer.md)
- 核准：使用者 2026-11-23 在 3D 討論串回覆「開工」

來自：[3F 觀課與環境教育室](2026-11-23-l3-learning-room.md)（TASK-131）的「不做」：3D 的 3F 室內交給 3D 串

## 目的

DEC-173 把 3F 分成觀課與環境教育室和設備區，模型、驗證與 3F 平面圖都已更新，但 3D 的 3F 還是舊的樣子：裡面兩道模型與平面圖都沒有的示意隔牆，其中一道橫過現在的教室；水塔沒有跟著 3F 樓板旋轉，畫出來穿過新的玻璃隔間、伸進教室約 7 公分。

## 範圍

- 網站模型：`core/viewer/viewer-data.mjs` 帶出 `l3.learningRoom`、`l3.equipmentZone`、`l3.glassPartition`；`model-adapter.ts` 檢查三者隨 3F 樓板旋轉、教室由到達翼進入、玻璃隔間在兩區之間、維修門上鎖、不作整班、鏡牆不開窗，不符就不畫。
- 場景（`web/src/views/3d-viewer/l3-learning-room.ts`，畫在 3F 旋轉群組裡）：
  - `W-L3-GLASS-01`：旋轉前 Y5.5 一道隔音玻璃，從外傾鏡牆接到端牆，框與豎框佔模型的隔間厚度；上鎖維修門照 3F 平面圖放在旋轉前 X39.5～X40.5，門上方是玻璃。
  - `Z-L3-LEARN-01`、`Z-L3-MEP-01`：兩區的地面範圍，可點選，說明取自模型與 DEC-173。
  - 教室的入口：到達翼只在端牆的一段貼著旋轉後的 3F，入口門畫在那一段的中間（寬 0.9 m，和景觀區的門相同）。
  - 示意設備：鏡牆那一側兩面觀課螢幕，玻璃隔間這一側一面能源看板，面向教室。
  - 可移動桌椅：三排、每排兩張桌子五張凳子，面向螢幕，加一張教師桌，共 15 個學生座位（約半班）；中級以上才畫，不參與碰撞。
- 拿掉 3F 裡兩道示意隔牆（模型與平面圖都沒有，其中一道橫過教室，違反「教室內不設固定隔間」）。
- 3F 的水塔與兩組設備照 3F 平面圖改畫在旋轉前的樓板座標，隨 3F 樓板旋轉，留在玻璃後的設備區；尺寸與圖層不變。
- 3D 契約：3F 的分區寫進契約；「高位設備只在固定支承帶，不隨旋轉 L3 懸挑」改寫成照平面圖隨 3F 樓板旋轉、靠近支點與直接支承線、不放在懸挑端。

不做：

- 3F 室內燈光：3F 是有屋頂的封閉量體，屋頂開著時室內照不到陽光、也沒有燈；要看室內須在圖層關掉「屋頂」與「能源」。
- 漫遊時 3F 的牆與玻璃隔間沒有碰撞（和現在的 3F 外牆一樣）。
- 攝影機、螢幕、看板的規格與畫面內容；人數上限、電梯、隔音等級（`OPEN-009`）。
- 平面圖上的直接支承線（虛線）在 3D 裡沒有畫。

## 驗收

- 從教室任一處往鏡牆橫掃，第一道清水模就是鏡牆內面；教室裡沒有設備；從教室看向設備區先穿過 Y5.5 的玻璃，水塔在玻璃後面；入口門在端牆貼著到達翼那一段；維修門在旋轉前 X39.5～X40.5（單元測試，合併前後的場景都測）。
- 繪製呼叫不超過 `core/viewer/render-budgets.mjs` 的上限。
- 屋頂開著的預設畫面不變；關掉屋頂與能源圖層後看得到兩區、玻璃隔間、螢幕、看板與桌椅（桌機與手機前後對照）。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過。

## 需要使用者確認

- 3D 契約原本寫「高位設備只在固定支承帶，不隨旋轉 L3 懸挑」，舊的 3D 照字面把設備畫成不旋轉；3F 平面圖與 DEC-173（水塔留在玻璃後）則是把設備畫在旋轉的樓板上。這次 3D 照平面圖改，契約也跟著改寫。若原意是設備真的不隨樓板旋轉，平面圖與 DEC-173 的水塔位置要另外調整。
- 維修門的位置只寫在 3F 平面圖的產生程式裡，模型沒有；這次 3D 照抄同一個數字。建議之後把門的位置寫進模型，兩邊都從模型讀。

## 結果

2026-11-23，雲端環境（Chromium 軟體繪圖），與 main 6013c86 比對，晴天 6 月 10 日 10:00：

- 畫面：關掉「屋頂」與「能源」圖層後，3F 看得到兩區、玻璃隔間與維修門、鏡牆那一側的兩面螢幕、隔間上的能源看板、15 個座位的桌椅與教師桌，端牆上有通到達翼的門；水塔與兩組設備在玻璃後。屋頂開著的預設總覽與改之前相同（三種畫質逐像素比對，只有水面動態的零星像素不同）。前後對照截圖在專案檔案區 `3d-review/l3-room-desktop.png`、`3d-review/l3-room-mobile.png`。
- 效能：總覽的繪製呼叫高畫質 204 → 213、中畫質 169 → 178、省電級 97 → 102（上限 500／200／200）；三角形多約 1,600（省電級多 280）；著色器程式高與中畫質多 2 支，省電級不變。門鎖改用框的材質，少一次繪製。
- 測試：新增 `tests/unit/web/views/3d-viewer/l3-learning-room.test.mjs`（射線檢查教室沒有固定隔牆與設備、玻璃在 Y5.5、水塔在玻璃後、入口與維修門的位置、桌椅在教室內，合併前後的場景都測；網站模型不符 DEC-173 時拒畫）；瀏覽器測試的選取清單加上 `Z-L3-LEARN-01` 與 `W-L3-GLASS-01`。

已知的限制：

- 3F 室內沒有燈，屋頂開著時看不清楚；漫遊時 3F 的牆與玻璃沒有碰撞。
- 螢幕與看板是深色面板，沒有畫面內容；桌椅的排法是示意，不是家具配置。
- 平面圖的直接支承線（虛線）在 3D 裡沒有畫。
