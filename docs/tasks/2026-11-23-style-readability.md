# 樣式可讀性：網站字型、色票、字級與焦點框

- 核准：使用者 2026-11-23 在討論串說「開工」，開始樣式階段二；方案文件列的建議值（載入字型、結語改宋體、不做深色模式）沒有異議，照建議做
- 前一步：[樣式打底](2026-11-22-style-foundation.md)（TASK-170）

來自：[網頁樣式審查與改善方案](https://claude.ai/artifact/WTV9jhHer5b5eiMjk3GBDj)〈實作順序〉階段二，處理問題 H3、H4、H5、M9、M10

## 目的

審查時量到：網站設定了思源宋體與思源黑體，卻沒有提供字型檔，所以每台裝置看到的標題字型與粗細都不一樣（Windows 會退回新細明體）；次要文字的灰色在紙色上只有 4.34:1，低於 4.5:1 的標準，四頁桌機合計 163 處不合格；網頁文字有 97 處小於 12px，最小 9px；可以點的東西多半沒有滑過與按下的回饋；中文標題套用負字距、中文副標套用等寬字型與字距。

這一步讓每台裝置看到同一套字，文字都讀得到，鍵盤與滑鼠操作都有回饋。版面與標題層級不動，那是階段三、四。

## 範圍

字型（[DEC-211](../decisions.md)）：

- 新增 `tools/build/build-fonts.mjs`（`npm run build:fonts`）：從 `@fontsource-variable/noto-sans-tc`、`noto-serif-tc` 的切片中，只取網站原稿實際用到的字（`content/`、`web/src/`、`drawings/current/`、`model/`、`core/` 裡的字元，加上英數與常用中文標點），用 `subset-font` 切成子集，字重軸只留 400 到 700，輸出到 `web/src/generated/fonts/`（不入庫）。
- `prepare`、`predev`、`build` 都會先跑；字集沒變時直接跳過。其他人加新文字不用做任何事，下一次建置就會收進來。
- 字型檔放在網站自己的網址底下，不連外部字型服務；`font-display: swap`，載入前先顯示系統字型。
- 字體串改成 `"Noto Sans TC Web"`、`"Noto Serif TC Web"` 開頭；拿掉 Inter、Georgia 與標楷體的指定，結語改用較大的宋體。

色票（`tokens.css`）：

- 次要文字 `--site-muted` 由 `#697273` 調為 `#586263`（5.5:1）；控制項邊框 `--site-line-strong` 由 `#8d928f` 調為 `#7f8582`（3.3:1）；新增段落文字 `--site-text`（`#4d5657`，6.6:1）。
- 新增圖表與 3D 共用的資料色 `--site-data-*`（冬季光、夏季光、鏡牆、水、固定量體、旋轉量體），只畫線與面，不當文字色。日照頁原本自己的色票改為引用這些變數；3D 串在執行時讀同一組 CSS 變數，不另做 JSON。
- 日照頁、圖面頁原本自己的墨色（深藍）與紙色改用全站的墨色與紙色。

字級（`tokens.css`）：

- 新增 `--site-text-xs`（12px）、`-sm`（14px）、`-md`（16px，桌機 17px）、`-lead`（18 到 20px）、`-h4`（20px）。四頁網頁文字中 20px 以下的固定字級全部改用這幾級，最小 12px：頁尾由 11.8px 改為 14px，頁首版號與頁面副標由 10.9px 改為 12px 與 14px，圖面頁籤代碼由 10px、資訊列由 9.9px、日照滑桿刻度由 9px 都改為 12px，圖面工具列按鈕由 11px 改為 14px。
- 20px 以上的標題字級不動，留給階段三統一頁面首區與標題層級時一起訂。
- 字重只用 400、500、700。

互動與中文排版：

- 全站同一種焦點框：赭紅 2px，框與元件之間墊一圈紙色，在紙面、照片與 3D 畫布上都看得見；日照頁兩處自訂的淡藍焦點框拿掉。
- 補上滑過與按下狀態：主導覽（滑過時文字變深、底線變灰，按下時底線變赭紅）、設計理念頁的四個方向索引與頁尾三個延伸連結、圖面工具列按鈕。
- 中文標題取消負字距；頁面副標改用黑體、不加字距；英文大寫小標才用大寫與字距。版本與座標仍用等寬字型，數字讀值改用黑體的等寬數字。
- 全站加上嚴格避頭尾（`line-break: strict`）與中英數自動間距（`text-autospace`），原稿不必手打空格。

不做（之後再做）：

- 3D 展示頁的樣式檔一行未動。3D 頁的三個小標（9px，赭紅 3.48:1）、操作提示與圖例（9px）、只靠顏色區分的圖層狀態，等 3D 介面改版時處理；改版時直接用新的字級與色票變數，已通知 3D 串。
- 圖內文字（日照圖、圖面 SVG、首頁主視覺）仍小於 12px，屬階段四的日照頁重排與圖面檢視器。圖面頁 `.drawing text` 把圖內字統一成 13px 的那條也留到階段四，現在刪掉會讓圖內字變小。
- 日照頁其餘寫死的色碼（底色、框線）在階段四重排時改成變數，之後再加 stylelint 禁止變數以外的色碼。
- 原稿裡手打的空格（例如「從 紙上的」）屬文案，不在樣式範圍。
- 圖面 SVG 的 class 前綴：清單已交給程式碼串（TASK-165，前綴 `dw-`）。

與其他進行中工作的先後：協調者排在設計架構的導覽 PR、TASK-164、#30 之後合併。導覽 PR 也改 `tokens.css`、`layout.css`，後合併的一方接 main 時處理衝突。

## 驗收

- 四頁（設計理念、日照研究、圖面三張、關於）在 1440 與 390 寬：axe（WCAG 2.2 AA）的對比不合格為 0，網頁文字（不含 SVG 圖內文字與只給讀屏軟體的文字）小於 12px 為 0。
- 1440 到 320 共 10 種寬度，改動前後比對，沒有新出現的文字溢出、被裁切或整頁橫向捲動。
- 每頁實際下載的字型量有量測並回報。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過；新增 `tests/unit/tools/build/build-fonts.test.mjs`。

## 結果

2026-11-23，雲端環境（Chromium）：

- 對比不合格：四頁桌機 163 處、手機 135 處，降為 0。小於 12px 的網頁文字：桌機 97 處、手機 89 處，降為 0。
- 字型子集：網站用到 1,236 個字元，黑體 31 個檔 398KB、宋體 31 個檔 530KB。瀏覽器只下載頁面上出現的字所在的檔，每頁第一次造訪實際下載：設計理念 841KB、日照研究 634KB、圖面設計 641KB、3D 展示 538KB、關於 707KB，換頁後已下載的檔會沿用。直接載入整套字型切片的話，設計理念頁要 2.4MB。
- 前後對照截圖（每頁電腦與手機）在專案檔案區 `style-audit/stage-2/`。
- 3D 頁維持原狀：對比不合格 3 處、小於 12px 的文字 18 處，見上面〈不做〉。
