## 驗收

2026-11-22：來源表 28 列與模型 `sources` 28 筆逐列一致，12 個新登錄檔案的雜湊、尺寸與位元組數都和檔案相符；把模型改回舊版時，`check:docs` 會列出 12 個缺漏。合規對照 18 列的模型值與狀態，由測試依 `GEO-0.10.0` 重算後通過。把 CMP-06 的狀態改成「符合」，或把引用未能覆核來源的 CMP-15 改成「符合」，測試都會失敗。對照結果：ST-02 級高、主池水深不符；無障礙廁所、無障礙浴室與教學平台水深符合；入口坡道、主入口寬度、衛生器具與救生器材待認定。畫面沒有變動。`npm run lint`、`npm run build`（234 個單元測試）、`npm run test:e2e`、`git diff --check` 通過。
