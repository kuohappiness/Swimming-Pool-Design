- 任務：TASK-161
- 核准：使用者 2026-11-22 在決定卡選「先做 4 和 6，5 和 7 等 3D 做完」，檢查通過即合併

## 目的

方案寫的時候圖面頁首次載入約 4 MB（直接讀原始衛星 PNG）；TASK-109 已改用 JPEG 衍生檔降到 572 kB，其中底圖占 457 kB、每一頁都會載入的頁首校徽占 70 kB（256 像素的 PNG，實際只顯示 32 像素）。手機用行動網路開圖面頁時，這兩張圖就占了大半流量。

## 範圍

| 項目 | 修法 |
| --- | --- |
| 圖面頁 `REF-001` 底圖 `site-satellite.jpg`（467,853 bytes） | 由原始 `SRC-SITE-001` PNG 直接轉成同尺寸 WebP（品質 85，333,948 bytes），與原始檔的 PSNR 40.0 dB，和原 JPEG（40.5 dB）相當 |
| 頁首校徽 `school-emblem-header.png`（256 × 256、71,133 bytes） | 縮成 96 × 96（三倍密度螢幕的 32 CSS 像素）WebP、保留透明（4,688 bytes） |
| 授權與來源登錄 | `LICENSE` 第三方段與 [基地與來源](../site-and-sources.md) 改記新衍生檔的尺寸與 SHA-256；原始檔不動 |

不做：

- 設計理念頁的照片：新增主題串正把 ORIGIN 圖廊移到 `design-process`，等搬完再處理，免得改到同一批檔案。
- 方案原列的「版本號改為建置時常數」：檢查後入口程式只帶入模型的六個頂層欄位，壓縮後 12 kB，效益不大，不改。
- 方案原列的「移除未啟用的後製程式碼」：3D 串的寫實升級已重做 rendering，由該串處理。
