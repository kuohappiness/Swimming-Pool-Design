# 1F 泳池使用動線與教學平台寫進模型

狀態：待審｜下一步：使用者審 PR 後合併，合併後補 0.10.0 發布紀錄｜等誰：使用者

來自：[DEC-157](../decisions.md)、[DEC-158](../decisions.md)、[設計架構決定落檔](2026-11-22-design-architecture-decisions.md)

## 目的

DEC-157、DEC-158 只寫在決定表時，模型、圖面與 3D 仍是舊的 1F：赤腳學生從 ±0.00 入口直接踩上 +0.30 m 池畔、沒有沖身與無障礙廁所、救生只有文字。這個任務把八處修改與教學平台變成唯一模型裡的幾何，讓驗證、圖面、3D 與漫遊從同一份資料長出來；不做的話，網站會繼續展示一個已經決定要改的設計。

## 範圍

- 模型：新幾何版本 `GEO-0.10.0`（`GEO-0.8.2` 改成 legacy 指標）；`l1.poolUse` 收入口換鞋玄關、坡道與兩階、乾式廊道與 1.1 m 低牆、梯底沖身區、AED、集合區、救生椅、無障礙暨親子室、管理暨急救室（含門與面池窗）、教具推車、移動式升降椅與一堂課路線；`l1.pool.teachingPlatform` 收可移除教學平台；取消乾式儲物間，水處理機房縮為 X34～X39。
- 驗證：`core/validation/model-validation.mjs` 檢查 DEC-157、DEC-158 的每一條規則，並附反例測試。
- 圖面：1F 平面圖畫出八處、路線 1～5 與教學平台；四張圖以 `GEO-0.10.0` 重產。
- 3D：`web/src/views/3d-viewer/pool-use-details.ts` 畫出各處；池畔在玄關處留出 ±0.00；Y0 玻璃與 `EN-01` 在玄關與坡道段落到 ±0.00；X31 牆開兩室的門與窗；設備牆與支承候選移到 X34；Y0 帶的部分隨泳池剖視隱藏；教學平台在水面下。
- 漫遊：玄關是 ±0.00 的地面，坡道與兩階是由 ±0.00 到 +0.30 m 的斜面。
- 文件：設計基準、模型契約、3D 契約、圖面說明。

不做：文案改寫（TASK-119）、導覽與圖號（TASK-130）、3F（TASK-131）、swim-class 頁與 3D 一堂課導覽（新增主題串、3D 串，等本任務合併後照新動線做）。

## 驗收

- `npm run check:model` 通過，`l1.poolUse` 每個項目都有 entityId 與 SITE-XY bounds。
- 反例測試涵蓋：玄關高度、鞋櫃數、坡度、階高、低牆高度、沖身唯一通路、救生椅位置、服務室重疊、門寬、窗與門重疊、儲物間復活、升降椅類型、路線順序、平台水深與範圍。
- 3D 場景測試：各處可點選、玄關面在 ±0.00、Y0 帶隨剖視隱藏、平台面在水面下 `topWaterDepth`。
- 漫遊測試：玄關地面 ±0.00、坡道中點 +0.15 m、由玄關走上坡道後站在 +0.30 m。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過；桌機與手機截圖已看過。

## 結果

- 教學平台面水深先用 working 值 0.80 m，等使用者在決定卡上確認；改值只需改模型一處。
- 水處理機房 32.5 m² 接近 `OPEN-018` 估算下限 31.9 m²；不足時退回 37.75 m² 方案。
- 設備牆與支承候選由 X32.5 移到 X34，荷重路徑待結構驗證（`OPEN-016`）。
- 坡道、無障礙室淨空與救生配置仍待專業覆核（`OPEN-009`）。
- 四張圖一起重產後，北向箭頭改為 TASK-113 更正後的 143°（舊圖停在 0.6.7 的 127°），圖面測試改為比對現行模型版本。
- 版本升為 0.10.0（新幾何必須搭配新模型版本）；發布紀錄 `docs/releases/0.10.0.md` 在合併後以合併 commit 補上。
