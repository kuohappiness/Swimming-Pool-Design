## 目的

水循環、一堂游泳課、設計歷程、關於四頁是分節說明頁，各自上線時把同一份目錄列、章節標題、段落與卡片的樣式複製了一次（四頁 view.css 共 1,493 行）。複本已經走樣：水循環與游泳課的章標 35px，另兩頁 40px；卡片與步驟的編號 11.5px，低於全站 12px 的下限；字級多半寫死成 `.72rem`、`.92rem` 這類數值，沒有用設計變數；游泳課頁另外自訂了焦點框。之後再加分節說明頁，又會再複製一次。

## 範圍

- `web/src/design-system/components.css` 新增一組共用元件：
  - `.site-chapter-index`：橫向的章節目錄列（自動編 01、02⋯）；`.site-chapter-index--aside` 是關於頁的側欄版。
  - `.site-chapters`、`.site-chapter`、`.site-chapter-header`、`.site-chapter-intro`：章節容器、章標（`--site-text-h2`）、卡片標題、段落（`--site-text`）與連結。
  - `.site-cards`（三欄）、`.site-cards--two`（兩欄）、`.site-card`、`.site-card-number`：卡片格與編號（12px）。1000px 以下兩欄、760px 以下一欄。
- 四頁的 `index.ts` 只在原本的元素上「加上」共用 class，原有的 class、錨點與文案不動；`view.css` 刪掉與共用元件重複的規則，只留各頁自己的版面（圖表、平面圖、時間軸、版本對照、名詞表、常見問題）。
- 四頁剩下的字級全部改用設計變數；水循環圖表提示框的陰影色改由 `--site-ink` 調出；拿掉游泳課頁自訂的焦點框，改用全站統一的焦點框。

不做：

- 頁面內容、章節順序與錨點不變。關於頁的名詞表、常見問題、下載清單，設計歷程的時間軸與版本對照，游泳課的平面圖，水循環的圖表，各自只有一頁用到，留在該頁。
- 3D 頁與日照頁不在這一步。

## 驗收

- 四頁的章標在同一寬度下字級相同（桌機 40px、手機 28px），頁內沒有小於 12px 的文字。
- 四頁的錨點、目錄連結、外部連結與點擊範圍照舊（既有瀏覽器測試不改）。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過；瀏覽器測試新增四頁共用元件、章標字級一致與最小字級的檢查。
