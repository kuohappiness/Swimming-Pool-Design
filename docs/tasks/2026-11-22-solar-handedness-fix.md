## 範圍

| 問題 | 修法 |
| --- | --- |
| 日照模組把 SITE +Y 當成方位角 37°，太陽與反射向量左右相反 | 方位換算只經 `core/geometry/site-orientation` 的 `siteVectorFromAzimuth`、`azimuthFromSiteVector` |
| L3 被當成數學正向（逆時針）旋轉，鏡牆法線因此不是 152.5° | 新增 `rotateSitePointClockwise` 與 `core/geometry/mirror-geometry`，鏡面角點只由這一個函式計算 |
| 年度能量、支點敏感度、淘汰角度的數值是在鏡像座標下算的 | 方法修訂為 `SOLAR-METHOD-1.1.0`，重算並更新模型、登錄檔、驗證器、設計基準、契約、分析文件與 OPEN-011 |
| 日照頁的「命中池面」在可選的 168 個時刻全部為否 | 改用與年度能量相同的反射範圍判定（`core/solar/pool-footprint`），168 個時刻中 42 個落在池面 |
| 頁面寫死「暖季零增量」、屋頂轉向數字與「07:00–17:00 年度能量時段」 | 數值由模型帶出；暖季顯示三位小數並註明不是零增量；說明年度能量逐時加總全天直射 |

不在範圍：重新搜尋角度或支點（待使用者決定）；圖面與 3D 的方位本來就正確，不動。
