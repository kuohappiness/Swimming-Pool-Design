## 目的

Vite 6 已不是目前的主線版本，之後的修正與安全更新只會進 8。先單獨升 Vite，TypeScript 與 Node 版本各自另開。

## 範圍

- `package.json`、`package-lock.json`：`vite` 由 `^6.3.5` 改為 `^8.3.8`。
- `vite.config.ts`：`build.rollupOptions` 改名為 `build.rolldownOptions`（Vite 8 改用 Rolldown 打包，舊名稱仍可用但已標為過時）。
- Node 需求不變：Vite 8 要 Node 20.19 或 22.12 以上，本專案 `engines` 已是 22.13 以上。

不做：TypeScript、Node 與其他套件升級；3D 程式本身。

## 打包結果的差異

- 網站所有 JS 壓縮後合計 446.1 kB → 446.3 kB，檔案數 105 個不變，`dist/web` 都是 8.6 MB。
- 分頁的程式包改用分頁名稱命名（例如 `solar-study-*.js`），不再是一串 `index-*.js`。
- CSS 改由 Lightning CSS 壓縮：屬性順序重排、顏色改寫成十六進位，壓縮後少約 1.3 kB。唯一看得到的差異是日照頁表格右緣捲動陰影的透明度 22% 寫成 `#1e292a38`（約 21.96%），截圖上差 1 個色階。
- 3D 的進階繪圖（`rendering/enhanced`）原本另成一包、在 3D 頁開起來後才載入；Rolldown 因為 `rendering/index.ts` 也直接匯出它，改併進 3D 主程式包（1,028 kB → 1,131 kB）。3D 頁預設就用進階繪圖，所以實際下載量相同，只是改成一次載完；只有網址指定基礎繪圖時會多載這一段。建置時會印出 `INEFFECTIVE_DYNAMIC_IMPORT` 提示。要恢復分包，得把 `rendering/index.ts` 的 `export * from './enhanced'` 拿掉並改測試的引用路徑，屬 3D 程式整理，排在 3D 型別規則那一批一起做。

## 驗收

- 改前與改後各建置一次，比對打包結果（上一節）；3D 以外 7 個分頁在 1440×900 與 390×844 整頁截圖，13 組逐像素相同，日照頁手機寬度一組只在表格捲動陰影差 1 個色階。3D 畫面由 `test:e2e` 的冒煙測試涵蓋。
- `npm run lint`、`npm run build`、`npm run test:e2e`（含 3D、日照、圖面冒煙與各分頁五種視窗）、`git diff --check` 通過。
