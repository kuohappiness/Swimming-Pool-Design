# 樣式各頁版面：日照頁重排、圖面檢視器與首頁重排

狀態：已合併｜完成：日照頁桌機兩張圖固定在左欄、圖面平移縮放檢視器、首頁手繪立體圖主視覺與每章一個標題｜等誰：—

- 任務：TASK-173
- 決策：[DEC-213](../decisions.md)
- 核准：使用者 2026-11-23 在討論串說「自動合併，可以開工」，開始樣式階段四
- 前一步：[樣式外框與手機](2026-11-23-style-frame.md)（TASK-172），本任務疊在它之上

來自：[網頁樣式審查與改善方案](https://claude.ai/artifact/WTV9jhHer5b5eiMjk3GBDj)〈方案二：各頁版面〉與〈實作順序〉階段四

## 目的

審查時看到：日照頁桌機在控制項上方另放一份縮小的「即時預覽」，真正的平面與剖面圖在左欄，調滑桿時往下捲就看不到圖，左欄下半整片空白；結論放在互動模型之後；表格在手機上捲動時看不到首欄。圖面頁只能在「符合畫面」與「原圖尺寸」二選一，手機上原圖尺寸要左右捲很遠，也不能放大看局部。首頁主視覺是一張縮小的三樓平面圖，圖內字只有 5 到 6px；每章有兩個 H2（側邊的「向光」與內文的「向光而轉」），版面左右交錯成三欄；「設計細節」十一項排成一長條。

## 範圍

日照頁：

- 桌機（1000px 以上）取消重複的即時預覽：左欄是平面與剖面兩張圖上下排列並隨捲動固定，右欄是控制項與讀值，調任何滑桿時兩張圖都在畫面內。圖下方的說明移到控制欄最上面。
- 窄螢幕（999px 以下）維持原本固定在頁首下方的單一預覽。
- 結論移到互動模型之前。
- 表格可用鍵盤捲動、首欄凍結、左右緣有可捲動的陰影提示。
- 寫死的色碼改用共用色票；控制項說明由 12px 提高到 14px。

圖面頁：

- 新增圖面檢視器（`web/src/views/drawings/pan-zoom.ts`）：圖紙一開始整張符合畫面；拖曳平移，雙指或按住 Ctrl 加滾輪縮放（一般滾輪仍捲動頁面），工具列有縮小、倍率讀數、放大、符合畫面與全畫面；檢視框可用鍵盤聚焦，＋、－ 縮放，方向鍵平移，0 回到符合畫面。倍率 100% 到 800%。
- 取代原本的「符合畫面／原圖尺寸」切換。列印前自動回到符合畫面。

首頁：

- 首區左文右圖，主視覺佔六成寬，用早期手繪立體圖（SRC-CONCEPT-020）當過渡圖；這張圖從手稿圖廊移到主視覺，圖廊不再重複。「設計從保留開始」接在首區之後，內文欄寬 38 字。
- 每章只有一個 H2，編號放在標題上方；內文一欄（38 字寬）加一欄配圖，不再左右交錯。三樓平面圖從首區移到「向光而轉」當配圖。
- 「設計細節」改成兩欄卡片格，含清單的「尚未完成的專業檢核」跨滿整列。
- 「結語」標題與內文同一欄。

不做（之後再做）：

- 3D 頁的介面與全畫面漫遊：照協調安排，避開 3D 頁與游泳課頁，等 3D 介面改版。
- 首頁四張方向卡的實證圖、關鍵數字列、主視覺正式影像：要 3D 串的固定視角靜態圖與資料正確性串的狀態標記，現在先不放佔位圖與數字。
- 首頁圖廊移到設計歷程頁：屬設計架構串的頁面內容分配。
- 「設計細節」方案原寫三欄：內容現在是十項加一項長說明，三欄會剩一張落單，兩欄五列剛好排滿，卡片寬度也落在 32 到 40 字。
- 日照圖內標籤避讓、圖面圖紙本身的字級與標註重疊：改繪圖程式，屬程式碼串。

## 驗收

- 日照頁 1024、1280、1440 寬：拖曳任何滑桿時平面與剖面兩張圖都完整在畫面內；999px 以下預覽照常同步。
- 圖面頁 390 與 1440 寬：預設整張圖紙在檢視框內、頁面沒有橫向捲動；按鈕、鍵盤可縮放平移，一般滾輪不會縮放。
- 首頁：每章一個 H2；設計細節桌機兩欄、手機一欄。
- axe 與 1440 到 320 共 10 種寬度的溢出檢查沒有新問題。
- `npm run lint`、`npm run build`、`npm run test:e2e`、`git diff --check` 通過；新增檢視器單元測試，瀏覽器測試涵蓋日照頁桌機固定圖、圖面檢視器與首頁結構。

## 結果

2026-11-23，雲端環境（Chromium），與 TASK-172 的建置比對：

- 日照頁：1024、1280、1440 寬調整控制項時，兩張圖都完整留在畫面內（改動前捲到控制項時兩張大圖都已離開畫面，只剩縮小預覽）。
- 圖面頁：390 寬放大到 225% 後可平移看局部，頁面沒有橫向捲動。
- 首頁：每章由兩個 H2 變一個；「設計細節」桌機高度 1,932px 降為 1,577px；首頁總高度桌機 13,510px 降為 12,980px，手機 12,643px 變 12,719px（多了主視覺圖）。
- axe：六頁在 1440 與 390 寬的違規項目與改動前相同（日照頁與圖面頁 SVG 的 aria 屬性、3D 頁對比都是改動前就有的）。1440 到 320 共 10 種寬度沒有新出現的溢出或裁切。
- 前後對照截圖在專案檔案區 `style-audit/stage-4/`。
- 單元測試把日照頁「桌機即時預覽」的斷言改成「只留窄螢幕預覽」，因為那份預覽就是這次刻意拿掉的重複。
