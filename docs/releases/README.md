# 發布紀錄

本目錄只保存已完成版本的不可變證據。每個正式版本使用 `<version>.md`，至少記錄發布日期、package version、modelVersion、revision、完成 TASK、主要 DEC、驗證命令與結果、release commit，以及 tag／push 狀態。

尚未完成的版本工作只存在於 [進度與任務](../roadmap.md)，不得預先在此建立看似已發布的紀錄。
