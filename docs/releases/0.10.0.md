- 鞋子在 ±0.00 換鞋玄關脫下，經 1:12 坡道或兩階上 +0.30 m 乾式廊道（1.1 m 低牆與止水緣），到 ST-01 梯底的洗腳池與 3 支沖身後才進池畔。
