## 方位根因修正

- 307° 是從真北順時針量到 SITE +X 的羅盤方位；Three.js root 改以 `90°−307°=143°` 建立，而不是直接使用 `−307°`。
- SITE +X 在世界中正確指向西北 307°，真北在 SITE 平面指向右下；3D 箭頭尖端增加 N，固定螢幕提示顯示「真北 N ↘」。
- 方位值、world rotation、plan direction、場景箭頭與螢幕提示均由同一 adapter 推導並由測試鎖定。

## 建築本體擬真

- 外殼加入清水模分割／螺桿孔、玻璃底座／膠條、天溝／落水管、屋頂轉接泛水與封膠。
- 泳池大廳加入溢流格柵、池底水道線、池畔排水、天花照明／通風、少量濕痕與高階焦散；水面 normal 依 frame state 更新。
- L2 加入 30 組淋浴頭／管線／排水、高階閥件、置物櫃門縫／把手、磁磚、照明、通風與少量濕痕。
- 時間狀態固定為「剛完工但已投入使用」；材質乾淨完整，只保留濕區合理使用痕跡。校園環境精化留到第二階段。

## 衛浴

- Viewer schema 1.4.0 為每個 L1 WC 隔間加入類型、中心與朝向。
- 全案 8 座 WC 固定為 4 坐式／4 蹲式：泳池男坐／蹲；泳池女坐／蹲／蹲；操場男坐；操場女蹲／坐，靠 X39 入口者為坐式。
- 坐式／蹲式 WC、洗手槽與小便斗均改為具盆深、座圈／腳踏、沖水五金、龍頭、鏡面、排水與感應層次的程序模型；隔間加入門片、腳座與鎖／鉸鏈。
- fixture center、朝向、總數與逐房順序均由 validator／測試 fail closed；器具法定數量、無障礙、防水、排水與管道仍受 OPEN-008 專業核定。

## 畫質與手機降階

- `EnhancedDetailLevelAdapter` 將 low／medium／high 對應 essential／reduced／full；切換與 dispose 可逆。
- low 只保留必要輪廓與基本水面，關閉細節陰影、焦散與高階附件；medium 增加主要操作／構造細節；high 顯示完整五金、接縫、排水、濕痕、焦散與陰影。
- reduced motion 與非 high 不更新 high-only 焦散；水面 normal 在低階停止動畫。
- 靜態場景的 PCF 陰影圖改為按需更新；首次繪製後，只在場景、圖層、剖視、畫質或 WebGL context 恢復時重算，不改陰影外觀。
- 所有分級細節均為 `visualOnly`／`collisionExcluded`，不改 canonical bounds、selection、collision、player、water simulation 或 movement mode。

## 驗證紀錄

- 90 項完整 Node 測試、文件檢查、reference validation、TypeScript 與 production build 通過。
- desktop／390 × 844 E2E 覆蓋 enhanced、Inspect、Walkthrough、七區（含一樓衛浴）、入水／水下、touch、snapshot restore、explicit baseline、necessary failure fallback、WebGL static fallback、solar-study 與 V067 atlas。
- 14 張 desktop high 視覺快照覆蓋五場景、池側／校側／俯視／泳池剖視及 L1／L2／L3／衛浴人眼視角；人工檢查新增外殼、泳池、衛浴、照明、排水與材質細節，未見新增 browser error。
- SwiftShader 相對證據為 high `0.86 FPS／2,017 calls／106,082 triangles`、medium `0.86／1,886／92,426`、low `8.55／618／30,654`，390 × 844 自動 low 為 `18.2 FPS／561／29,764`；全部高於同機 v0.6.7 baseline 的 80% 門檻且符合資產預算。軟體繪圖 FPS 不冒充硬體驗收。
- 自我優化以明確 shadow caster 保留主要器具陰影、low 關閉細節陰影，將衛浴 mesh 由 272 批次化為 160，並加入 180 上限回歸測試與靜態陰影按需更新。視覺快照與較慢的效能量測分離，腳本提供首幀診斷與 `--sanitary-only` 快速檢查，並於 `finally` 關閉 browser／preview，不保留常駐伺服器。
