## 從現場與手稿開始

- 設計理念在作品首屏後加入 `00 / ORIGIN`，閱讀順序成為「現場觀察→手稿推演→四個設計方向→日照→圖面→3D」。
- `SRC-CONCEPT-012`～`SRC-CONCEPT-023` 共 12 個原始檔完成 MIME、bytes、dimensions、EXIF、SHA-256、日期、用途與權利登錄；原始位元組不做旋轉、裁切或重新壓縮。
- HTML 依使用者指示只使用校園場勘 2／5／6，以及俯視、剖面、早期 3D、日照反射與日照研究五張手稿；場勘 1／3／4 與樓梯概念圖只保存來源，不被頁面引用。
- 公開版以現場 00A、手稿 00B 兩段編排，共八張圖片與逐張圖說；沒有輪播、自動播放、視差或假手稿。

## 圖片效能與可讀性

- 八張公開影像各產生 960 px／1920 px JPEG 衍生檔，共 16 檔；依 viewport 與顯示寬度由 `srcset`／`sizes` 自動選擇。
- 所有 ORIGIN 圖片使用 lazy loading 與 async decoding；尚未捲到段落前不下載，不把 6～9 MB 原始場勘照片直接送入 HTML。
- 衍生檔只做 EXIF 方向校正、等比例縮放與壓縮，不裁切手稿內容、不抹除紙張與筆跡。960 px 檔約 53～168 KB，1920 px 檔約 168～619 KB。

## 專注的 3D 展示

- 3D view 改用 App Shell 內的 fragment，不再搬入舊完整 HTML document，也不再重複渲染整篇設計理念。
- WebGL 與 static fallback 都只顯示當前場景短摘要、三個觀察點及返回完整理念的連結；Viewer 畫布更早成為頁面主角。
- 五場景、十圖層、固定視角、剖視、選取、畫質、七區漫遊、兩梯、游泳、水下、碰撞、safe spawn 與 Inspect snapshot restore 全數保留。

## 響應式與驗證

- ORIGIN 在桌機採非對稱刊物構圖與黏附標題，手機改為單欄；八張圖片的實際載入、自然尺寸、替代文字、來源順序與四個排除 ID 皆由 E2E 驗證。
- `npm run build` 通過文件、reference model、93 項 Node 測試、TypeScript 與 production build。
- `npm run verify:v091-baseline` 證明 active geometry design、solar inputHash、Viewer 幾何／漫遊語意與 8 個 V067 SVG／PNG hash 不變；只放行本版核准的公開理念文字變更。
- 公開站四 view × 五 viewport 通過 routing、accessibility、heavy-runtime isolation、reduced motion、圖片載入與無整頁水平溢出。
- Viewer、solar-study 與 atlas 的 desktop、mobile、WebGL fallback browser smoke 通過，漫遊完整回歸通過。
- 桌機與 390 px 手機的場勘、手稿實際截圖已人工檢查；壓縮後的鉛筆線、手寫字與粉紅紙張仍可辨識。

## 不可變資料與專業界線

- 0.9.1 是 presentation-only PATCH release；active geometry 維持 `GEO-0.8.2`，solar inputHash 與 V067 SVG／PNG 內容不變。
- 頂層 `modelVersion` 隨發布同步為 0.9.1，但不建立虛假的 `GEO-0.9.1`，不重跑日照最佳化，也不修改 Viewer 移動或碰撞資料。
- 本版仍是概念設計與公開展示成果，不是施工、結構、消防、機電、無障礙、材料、眩光、熱工或法規核定文件；`integrationReview.professionalApprovals` 維持全數 `false`。
