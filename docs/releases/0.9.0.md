## 統一公開成果展

- 正式部署只保留 `index.html`；`設計理念`、`日照研究`、`圖面設計`、`3D 展示` 由 `view` query 直入，共用唯一 header、導覽、版本與專業聲明。
- 預設首頁以「向光、向水、向人、向時間」編排完整公開理念正文，搭配現行 V067 圖面；內容與技術數值由 owner Markdown、generated content 與 active geometry token 產生。
- 共用設計系統採紙張、墨色、水色與陶土色，使用本機字型堆疊、刊物式留白與線條層級，不依賴外部字型、漸層、發光或過量卡片。
- query router 對未知值安全回退設計理念；舊 `/solar-study/` 與 `/3d-viewer/` HTML 不再建置，GitHub Pages workflow 會驗證單一 artifact。

## 專業研究、圖面與 3D

- 日照研究保留 v0.6.7 工作值、控制器、代表時刻、方法與專業限制；摘要直接讀 study owner 值，不另存第二份角度或 kWh，solar inputHash 維持 `3f9ae69b4dcd…`，未重跑最佳化。
- 圖面設計保留五張 current sheet、內嵌 SVG、ID 選取、圖層與 L3 太陽能控制；手機預設顯示完整圖框，可切回原圖尺寸檢視。
- 3D 展示以 view-level dynamic import 隔離約 771 kB 的 Three.js runtime；非 3D 初始 route 不載入重型 chunk。離開時停止 animation loop 並清理 ResizeObserver、listener、camera、input、selection、underwater、controls、rendering 與 renderer。
- 五場景、十圖層、固定視角、泳池剖視、構件選取、enhanced／baseline／static fallback、七區漫遊、兩梯、游泳、水下與 Inspect snapshot restore 全數保留。

## 響應式、無障礙與視覺

- 1440／1280／768／390／320 px 均驗證四個 route、active 導覽、無整頁水平溢出、44 px 導覽觸控、skip link、focus 與 reduced motion。
- 人工檢查理念、solar、V067 atlas 與 Viewer 的桌機／手機截圖；並修正 3D 首屏對比、手機圖面裁切及 sticky 導覽下的控制定位。
- 所有 runtime resource 只來自同一 origin；設計、solar、drawings route 不預載 3D heavy chunk。

## 不可變資料與版本語意

- 0.9.0 是 presentation-only MINOR release，active geometry 維持 `GEO-0.8.2`；頂層發布版號與 immutable geometry revision 已明確解耦。
- active resolver 要求 `id = GEO-${revision}`、幾何 `modelVersion = revision`，且 active geometry 不得比發布版更新；因此不會為展示層改版偽造 `GEO-0.9.0`。
- 改版前基線鎖定 active geometry design hash、Viewer geometry／interaction semantics、solar inputHash、公開理念 source hash、8 個 V067 SVG／PNG hash 及三入口桌機／手機截圖。
