## 3F 教室有門（DEC-175）

- 0.12.0 開樓梯口後，到達翼貼著教室端牆的那一段整段在樓梯口裡，教室沒有門。
- 到達翼往北延伸到教室端牆與 Y3.039，面積約 4.388 m²，扣樓梯口後可走 3.674 m²；景觀平台讓出這一塊後淨約 2.547 m²，L3 總面積不變。
- 教室門在端牆樓梯口外、隔音玻璃面之前那一段，長 1.081 m，可放 0.9 m 門。
