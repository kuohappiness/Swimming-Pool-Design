# Release 0.9.3

- 日期：2026-07-26

- Active geometry：`GEO-0.8.2`

## 手機閱讀與圖面操作

- 設計理念索引在手機版縮小標題並固定單行，最長的「向時間延續」不再換行。
- 四個理念章節在手機版直接顯示完整章名，隱藏內文開頭重複的同名標題；桌機仍保留短側標與完整章名的雙層排版。
- 手機章節引言改用內文字體，字級固定為內文的 110%。
- 圖面目錄左右邊緣依捲動端點顯示半透明漸層，提示尚有可水平滑動的連結，且不攔截觸控或點擊。
- `REF-001` 與 V067 圖面工作區在手機版撐滿可用寬度，工具列、模型資訊與縮放圖面不再留下右側空白。

## 不變邊界

- 本版是 mobile-only presentation PATCH；桌機／平板版面不變。
- active geometry 維持 `GEO-0.8.2`，不建立 `GEO-0.9.3`。
- solar inputHash、v0.6.7 研究基線與互動不變。
- V067 SVG／PNG 本體、3D Viewer 幾何、相機、圖層、選取、碰撞、移動、游泳與漫遊行為不變。
