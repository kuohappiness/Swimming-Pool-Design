## 3F 觀課與環境教育室（DEC-173）

- 旋轉前樓板座標 X29～X41／Y0～Y5.5 為觀課與環境教育室（66 m²），由到達翼進入；Y5.5～Y13.5 為設備區（96 m²）。
- 兩區之間是隔音玻璃隔間，留一樘上鎖維修門；水塔與除濕熱回收設備隔著玻璃看得到。
- 限教師、預約小組（約半班）與維修人員，不作整班教室。
- 觀課用池上與水下攝影機接到室內螢幕；鏡牆維持整面鏡面，不開窗、不改反射玻璃，日照分析不變。
- 能源看板同步放在 1F 換鞋玄關。
