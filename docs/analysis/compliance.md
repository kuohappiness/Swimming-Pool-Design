# 合規對照

本檔把現行模型的幾項數值，對照到〈[基地與來源](../site-and-sources.md)〉第 7 節登錄的法規來源。這是概念階段的自我檢查，不是法規審查或簽證；適用與否、例外與最終認定由建築師與主管機關決定。

規則（`DEC-160`）：

- 「模型值」由單元測試從 `model/project-model.json` 算出，和本表不一致時測試失敗。
- 「門檻」寫成 `≤ 數值 單位`、`≥ 數值 單位` 或 `數值～數值 單位` 時，測試依門檻判斷狀態，「狀態」必須相符；門檻寫 `—` 的列只能是「待認定」。
- 「來源」必須是已登錄的 `SRC-REG` 編號；來源狀態為「未能覆核」的列只能是「待認定」。
- 狀態只用三種：符合、不符、待認定。
